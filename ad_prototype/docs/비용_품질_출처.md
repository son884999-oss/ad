| 홍보 글 | `npm run eval:promo -- --live --count 3`(유료 호출이니 장부 먼저), AI 없을 때 `eval:promo --local` | 상투어·효능 표현·AI 말투·반복·첫 줄 길이·행동 유도·해시태그 |
| 포스터 | `npm run eval:poster`(PNG + 글자 대비·안전 영역·제품 면적) + 눈으로 | 대비 4.5:1 미만 −10, 안전 영역 밖 −10, 제품 25% 미만 −10, 제목 두 줄 넘게 −5, 사진과 안 어울리는 색 −5, 어색한 빈 공간 −5 |
| 영상 | `npm run eval:video`(보통 MP4·길이) + 프레임 캡처 | 제품·글자 일그러짐 −20, 회전·변형 −15, 깜빡임 −10, 자막 잘림 −10, 움직임 약함/셈 −5 |
| 화면 | `npm run audit:screens` 캡처를 UI/UX·가독성·접근성·프론트엔드 4관점으로, 가장 낮은 점수 | 한 화면 주 버튼 2개 이상 −10, 정렬 어긋남 −5(곳마다), 위계 불분명 −5, 쉬운 화면 어려운 말 −5, 측정 문제 1개당 −10 |

판단 기준: 고령 사용자에게 쉬운 쪽(큰 글씨, 적은 선택지, 한 화면에 한 가지 일), 한 화면에 주황 주 버튼 하나, 글자 14px 이상, 대비 4.5:1 이상, 누르는 곳 44px 이상(쉬운 화면 52px 이상).

마지막 점수판(10-17 루프 종료): 홍보 글 97~100, 포스터 100, 영상 100, 화면 100. 10-18 다중 에이전트 목표(고급형 포함 95점)는 79점에서 한도로 종료. 그 뒤 화면이 크게 바뀌어 다시 재야 한다.

#### 믹스 처리 (2026-10-19, `src/videoSound.ts`)

사용자가 소리를 "찌릿하고 뾰족하다"고 함. 측정하니 장면 전환 효과음이 2~4kHz(귀가 가장 예민한 대역)에 몰려 있고, 비발디(바이올린)는 4kHz 이상이 밝았음. 그래서 전체에 하이셸프(3kHz 이상 -8dB), 효과음에 로우패스(1.8kHz)·크기 0.3·0.04초 페이드인, 리미터는 -3dB 안전장치로만. 녹화 샘플 기준 2~4kHz 순간 최대 -15.5 → -22.3dB, 전체 음량은 -20.6 → -22.5dB(RMS)로 거의 유지, 최대 -7.3dB(깨짐 없음).

같은 날 사용자가 "배경음이 너무 세다"고 해서 음량을 낮춤: 배경음 0.9 → 0.52, 효과음 0.3 → 0.18. 녹화 샘플 -19.4 → **-24.2 LUFS**(말소리 아래 깔리는 광고 배경음 수준 -24~-28), 최대 -12.1dB. 인스타·유튜브는 올릴 때 음량을 다시 맞추므로 SNS에서는 크게 달라지지 않고, 앱 미리보기와 카톡·갤러리 재생에서 조용해짐.

시험 단계 설정(사용자, 같은 날): 배경음을 더 은은하게 — 배경음 0.3, 효과음 0.1. 녹화 샘플 **-29.0 LUFS**, 최대 -16.8dB.
