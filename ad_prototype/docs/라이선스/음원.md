## 믹스 처리 (2026-10-19, `src/videoSound.ts`)

사용자가 소리를 "찌릿하고 뾰족하다"고 함. 측정하니 장면 전환 효과음이 2~4kHz(귀가 가장 예민한 대역)에 몰려 있고, 비발디(바이올린)는 4kHz 이상이 밝았음. 그래서 전체에 하이셸프(3kHz 이상 -8dB), 효과음에 로우패스(1.8kHz)·크기 0.3·0.04초 페이드인, 리미터는 -3dB 안전장치로만. 녹화 샘플 기준 2~4kHz 순간 최대 -15.5 → -22.3dB, 전체 음량은 -20.6 → -22.5dB(RMS)로 거의 유지, 최대 -7.3dB(깨짐 없음).

같은 날 사용자가 "배경음이 너무 세다"고 해서 음량을 낮춤: 배경음 0.9 → 0.52, 효과음 0.3 → 0.18. 녹화 샘플 -19.4 → **-24.2 LUFS**(말소리 아래 깔리는 광고 배경음 수준 -24~-28), 최대 -12.1dB. 인스타·유튜브는 올릴 때 음량을 다시 맞추므로 SNS에서는 크게 달라지지 않고, 앱 미리보기와 카톡·갤러리 재생에서 조용해짐.
