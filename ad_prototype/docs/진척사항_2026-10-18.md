## 1. 지금 프로그램이 돌아가는 방식

```
① 사진 넣기   사진 → 만들 것(포스터/영상/글) → 기본형(무료) / 고급형(유료)
② 정보 입력   AI가 사진을 보고 이름·설명·특징을 미리 채움 [글 AI]
              (고급형 + 영상일 때만) "고급형 특별 연출" 스위치 — 기본 꺼짐
③ 결과        홍보 글: 서버 [글 AI] → 안 되면 앱 기본 문구
              포스터: 브라우저에서 그림 (사진 = 원본, 고급형이면 AI 배경 장면)
              영상:   아래 표
```

**[글 AI] 순서** (`api/_lib/gemini.js` `generateJson`): 기관 Claude(COPA, `claude-haiku-4`) → Gemini 무료 키 → Gemini 유료 키(하루 500원까지, `GEMINI_MODEL_2`) → 전부 실패하면 앱 기본 문구. 어느 단계든 실패(한도·오류·시간 초과·잘못된 답)하면 다음으로 넘어갑니다.

| 영상 | 만드는 방법 | 시간 | 비용 |
|---|---|---|---|
| 기본형 | 원본 사진으로 브라우저에서 6초 모션 영상: 확대 → 클로즈업·빛·특징 태그 → 가격·행동 유도 카드, 업종별 움직임(음료 김, 디저트 빛, 화장품 반짝임, 꽃잎), 합성음 (`src/motionVideo.ts`) | 약 6초 | 0원 |

### 영상 소리 문제 (사용자, 2026-10-18 밤)
"깨지는 소리 같은 듣기 싫은 소리가 난다." 코드를 보고 짐작한 원인(실제로 들어 보고 확인할 것):
- **"휙" 소리(whoosh)가 흰 잡음(`Math.random()`)을 대역 필터로 거른 것**이라 거칠고 지직거린다. 기본형 `App.tsx` `whoosh()`(2.35초·4.15초 두 번), 고급형 `videoCaptioner.ts` `addSound()`.
- **차임이 20ms 만에 최대 크기로 올라가서**(`exponentialRampToValueAtTime(level, +0.02)`) 시작할 때 "틱" 하고 튄다. 여러 음을 0.09초 간격으로 겹쳐서 순간적으로 커진다.
- **녹음 단계에서 소리가 잘릴 수 있다**: 여러 소리가 동시에 울릴 때 합이 1을 넘거나(고급형 `master` 0.9 + 패드 + 차임), MediaRecorder의 AAC 인코딩에서 고음이 깨진다.
- 고칠 방향: 잡음 "휙"을 빼거나 부드러운 사인 스윕으로 바꾸기, 차임은 시작 80~150ms에 걸쳐 올리고 음량을 절반으로, 마지막에 `DynamicsCompressor`(리미터)를 한 번 거치기, 확인은 만든 MP4를 파형·귀로 확인.

## 6. 고급형 구조 논의 (위 6-0으로 결정됨, 기록으로 남김)

### 오늘 본 사실
- 기본형 화면 구성(3장면·특징 태그·가격 카드)이 고급형 후편집보다 보기 좋다(사용자 평).
- 사진이 이미 광고 사진 수준이면(케이크·라테 시험 사진) 기본형과 고급형 차이가 작다. **평범한 휴대폰 사진(마카롱)에서는 배경 바꾸기 효과가 확실하다.**
- 배경 바꾸기는 Gemini 3.1 그림 모델로 Higgsfield 장면만큼 되고, 더 빠르다(13~25초 대 약 1분). 단 **제품이 바뀌는 경우가 있다**(마카롱 색·개수).
- Higgsfield만 할 수 있는 것은 "실제로 움직이는 장면"(김, 세계 전환)이다. 콘셉트 영상은 실제로 1번만 확인했고 가짜 글자·밀가루가 제품을 덮음·제품이 작음 문제가 있었다.

### 안 A — 3단계 (처음 제안)

| | 사진 | 영상 | 시간 | 비용 |
|---|---|---|---|---|
| 기본형 | 원본 | 기본형 모션 | 6초 | 0원 |
| 고급형 | Gemini 광고 배경 | 기본형 모션 | 약 20초 | 장당 26~60원 |
| 고급형 + 특별 | Gemini 광고 배경 | Higgsfield 움직임 + 후편집 | 1~3분 | + 약 300~450원 |

### 안 B — 2단계 (사용자 제안, 권장)

```
기본형 (사장님에게는 무료)
  사진 → Gemini 광고 배경 (실패하거나 하루 상한이면 원래 사진)
       → 포스터 + 기본형 모션 영상 + 홍보 글
       → 결과에서 "바뀐 사진 / 원래 사진" 고르기

고급형 (시연 코드)
  기본형 전부 + Higgsfield 움직임 영상(지금의 "특별 연출") + 후편집
```

좋은 점: 등급 차이가 분명하다(기본형 = 사진이 예뻐짐, 고급형 = 움직임). 기본형 품질이 크게 오른다. 충전한 Higgsfield 금액은 고급형에만 쓴다. "특별 연출" 스위치가 필요 없어진다(고급형 자체가 특별).

걸리는 점과 대책:

| 문제 | 왜 | 대책 |
|---|---|---|
| 제품이 바뀜 | 기본으로 쓰는 모든 사장님이 그 위험을 떠안음 | 결과에서 "바뀐 사진 / 원래 사진" 고르기. 근본 해결은 "제품 오려 내기 + AI 배경 합성" |
| 기본형이 유료 호출이 됨 | 장당 26~60원, 하루 500원 상한이면 하루 10~20장 | 상한·실패 때 원래 사진으로 자동 진행(지금 기본형 그대로). 사장님 화면의 "무료"는 유지 가능 |
| 누구나 호출 가능 | 기본형에는 시연 코드가 없음 | Higgsfield와 같은 보호(주소당 분당 횟수, 하루 상한, 결제 키)를 Gemini 그림에도 건다 |
| 고급형 검증 부족 | 콘셉트 영상 실제 확인 1번, 문제 있음 | 프롬프트 보강 후 유료 영상 1~2번으로 확인 |

### 사용자가 정할 것
1. 안 A / 안 B.
2. (B라면) 기본형에서 배경 바꾸기를 **항상** 할지, **스위치로 켤지**. 항상: 품질↑, 비용·위험↑. 스위치: 안전, 안 켜는 사람이 많을 수 있음.
3. Gemini 하루 상한(지금 500원)이 시연·초기 배포에 충분한지.
4. 고급형의 Higgsfield 영상을 "세계가 바뀌는 콘셉트" 하나로 갈지, "천천히 다가가기"(안전)도 남길지.
5. 제품이 바뀌는 문제: (가) 프롬프트 보강("색·개수·놓인 모양 그대로", 마카롱 1장 시험) → 안 되면 (나) 오려 내기 + 합성.
6. 기본형 합성음이 "조금 튄다" — 차임 크기·시작을 부드럽게(구조가 정해진 뒤).
