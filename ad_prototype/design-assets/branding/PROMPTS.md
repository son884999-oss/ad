# Phase 4-A 이미지 생성 기록

2026-10-09. `imagegen` 스킬의 내장 `image_gen` 모드. CLI/API fallback은 사용하지 않았다. A–E 각각 별도 생성 요청이며 모든 요청의 `transparent_background`는 `true`였다. 글자는 생성 모델에 맡기지 않고 `build-brand-concepts.mjs`로 정확한 **홍보잇다**의 글리프를 SVG path로 구성했다.

## A 최초 생성

```text
Use case: logo-brand
Asset type: 홍보잇다 브랜드 탐색 A안, 심볼 단독, 정사각.
Primary request: 작고 독창적인 뫼비우스 리본 로고. 비스듬히 기울어진 둥근 삼각형 또는 부드러운 육각형 고리 하나를 폭이 일정한 두꺼운 리본으로 만든다. 중앙 빈 공간 하나, 아래 오른쪽에 단 한 번의 접힘. 연속된 하나의 길이 소상공인과 고객을 연결한다는 인상. ∞ 기호와는 다른 단일 고리 실루엣.
Style: 높은 수준의 실제 상업용 로고 디자인, 완전히 평평한 벡터 느낌, 절제되고 따뜻함. 대칭에 가까운 안정된 균형, 두툼하고 간결한 면.
Color: 리본 주면 warm orange #E88942, 접혀 돌아가는 작은 한 면 deep navy #26364A. 정확히 두 단색. 뒷면의 색 구분 외에 음영 없음.
Composition: 중앙에 심볼 하나만 크게, 사방 약12% 여백. 32px에서도 식별 가능한 열린 중앙.
Background: genuine transparent alpha.
Constraints: 어떠한 글자·숫자·한글·영문·워터마크도 없음. 목업, 명함, 종이, 배경, 격자, 설명, 반사, 그라데이션, 그림자, 3D, 가는 선, 무한대 기호, 사람 모두 금지. 한 개의 완성된 심볼만.
```

원본: `concept-a/original-v1.png`.

## A 보정 요청

입력 이미지: A 최초 생성 파일. 형태를 보존하는 편집 요청이며 결과를 `concept-a/selected.png`로 저장했다. 생성 원본의 미세한 색 변화까지 모두 제거되었다고 주장하지 않는다.

```text
Use case: precise-object-edit
Edit target: 제공된 A안 삼각형 리본 로고.
Change only: 로고 모양·비율·빈 공간·오른쪽 아래 접힘은 그대로 두고, 오렌지 면을 완전 균일한 #E88942 단색으로, 남색 면을 완전 균일한 #26364A 단색으로 평탄화하세요. 모든 미세 그라데이션·광택·질감·음영 제거. 중앙 구멍 안의 얼룩도 제거하여 완전한 투명 alpha로. 배경은 진짜 투명 alpha 유지.
Constraints: 기존 심볼 그대로 유지. 글자·텍스트·새요소·그림자 추가 금지. 선명한 벡터 로고 품질. 단 두 색의 잉크면.
```

## B 생성

```text
Use case: logo-brand

Primary request: 소상공인-플랫폼-고객을 표현하는 세 개의 서로 맞물린 둥근 사각 링크. 가운데 작은 남색 둥근 사각 고리를 중심으로 왼쪽 아래와 오른쪽 위의 주황색 둥근 사각 고리 두 개가 하나의 계단형 순환 경로를 이룬다. 각 링크는 사각형이지 원형 체인이 아니다. 세 개를 겹쳐도 여백과 구멍이 분명히 보이며 전체 실루엣은 안정된 가로 비율. 서로 다른 세 주체가 오가는 디지털 플랫폼의 연결을 최소한의 형태로 표현.
Style: 일류 브랜드 디자이너의 극도로 간결한 2D 벡터 로고. 단색 인쇄용 평면 실루엣, 균일한 두툼한 폭, 작은 크기에 명확한 구멍. 색면은 정확히 #E88942와 #26364A 두 가지, 절대 그라데이션이나 빛이 없음.
Composition: 중앙에 심볼 하나, 정사각 캔버스, 12% 여백.
Background: genuine transparent alpha.
No text, no letters, no Korean, no number, no watermark, no mockup, no shadows, no textures, no gradients, no 3D, no border framing, no extra graphic. An original commercial symbol, not a stock chain icon.
```

## C 생성

```text
Use case: logo-brand
Asset type: 홍보잇다 로고 탐색 C, 심볼만.
Primary request: 서로 주고받는 홍보 흐름을 표현하는 독창적인 비대칭 무한 루프 로고. 왼쪽은 넓고 낮은 부드러운 사각 고리, 오른쪽은 조금 작고 위로 향한 둥근 물방울 고리. 두 고리는 중앙을 지나며 자연스럽게 한 리본으로 연결. 일반 수학 ∞ 기호처럼 양쪽이 대칭이거나 가는 선이 아니다. 왼쪽의 수평 기반과 오른쪽의 상승감으로 상호 성장 표현. 간결한 두꺼운 단색 리본, 중앙의 교차부는 작은 명확한 간격으로 앞뒤를 구분.
Style: 매우 세련된 미니멀 2D 벡터 로고, 32px 앱 아이콘에서도 두 구멍과 전체 실루엣이 잘 보임. 주황 #E88942 한 색이 주인공, 교차부의 짧은 면만 navy #26364A. 각 면 완전 단색으로 채움. 브랜드용 정교한 베지에곡선.
Composition: 가로형 기호 하나를 정사각 중앙에, 양옆12% 여백, 충분히 굵은 리본.

Constraints: 글자 한글 영문 숫자 전혀 없음. 사람 없음. 그라데이션, 그림자, 금속, 3D 렌더, 배경판, 테두리, 텍스처, mockup 없음. 다른 회사 로고를 참조하지 않음.
```

## 저장·조합 처리

- 각 생성 원본은 해당 `concept-*/selected.png`에 보존한다. 원본의 SHA-256과 픽셀 크기는 public의 `manifest.json`에 있다.
- 배포용 `symbol.webp`는 원본의 투명 여백을 정리하고 512px로 축소한 파일이다. 심볼 구조를 코드 그림으로 대신하지 않았다.
- `wordmark.svg`는 정확한 네 글자의 실제 글리프 윤곽이다. A–E의 자간을 조절했고 D는 ‘잇다’의 색과 별도 연결 획을 더했다. 받침과 연결 획이 닿지 않도록 시각 검토 후 간격을 보정했다.
- `horizontal.svg`는 생성 심볼을 내장한 raster+vector 혼합 SVG다. 완전한 벡터 심볼은 승인 후 제작 대상이다.
- 어두운 배경은 비교 페이지에서 흰색 단색으로 시연했다. 32/96px도 같은 파일의 실제 표시 크기이며 불필요한 크기별 파일을 대량 생산하지 않았다.
