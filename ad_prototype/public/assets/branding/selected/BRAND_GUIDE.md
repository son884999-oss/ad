# 홍보잇다 — C안 ‘오가는 흐름’ 사용 기준

2026-10-09 사용자가 비교 이미지의 세 번째 안을 선택했다. 공식 이름은 **홍보잇다**다.

## 형태와 파일

왼쪽의 넓은 고리, 오른쪽으로 올라가는 끝, 남색 교차면을 유지한다. 가게의 소식과 손님의 반응이 오가는 연결을 표현한다. 원래 생성 이미지를 참고해 Bézier 경로를 정리했으며 자동 추적이나 생성 이미지의 픽셀 단위 복제는 아니다.

- `horizontal.svg`: 밝은 화면의 기본 로고. 심볼과 정확한 한글 윤곽을 포함한 순수 SVG.
- `primary-stacked.svg`: 심볼 위·한글 아래의 세로 기본 조합. 로그인처럼 좁은 중심 배치에 사용한다.
- `horizontal-reverse.svg`: 남색 등 어두운 단색 배경. 주황 심볼, 아이보리 교차면·한글.
- `wordmark.svg`: 정확한 한글 이름만 사용하는 경우.
- `symbol.svg`: 설명과 함께 사용하는 컬러 심볼.
- `symbol-mono.svg`, `symbol-reverse.svg`: 단색 인쇄·작은 보조 표식. 교차면 색 구분은 생략한다.
- `icon.svg`: 정사각 아이콘. 가로 심볼을 늘이거나 세우지 않고 아이보리 바탕에 배치.
- `apple-touch-icon.png`: 180×180px 홈 화면 아이콘.

## 크기와 여백

가로 조합의 비율은 700:180이다. 서비스에서는 기본 너비 182px, 359px 이하 화면에서 160px로 표시한다. 최소 권장 너비는 160px다. 로고 홈 버튼은 기본 48px 이상, 간편모드에서는 60px 터치 높이를 확보한다.

세로 기본 조합은 480:380, 로그인에서는 너비 160px다. 푸터에는 글자 중심 워드마크를 사용한다. 완성된 8개 구성은 `/brand-library/index.html`에서 함께 확인할 수 있다.

외부 배치 시 로고 바깥으로 최소 한글 높이의 1/4만큼 여백을 둔다. 주변 버튼과 이 여백을 공유하지 않는다. 심볼과 글자의 내부 간격·상하 정렬을 임의로 바꾸지 않는다.

16·24·32·96px 아이콘을 실제 브라우저에서 확인했다. 16px에서는 교차면보다 외곽 형태를 우선한다. 서비스명 인지가 필요한 곳은 심볼만 쓰지 않고 한글 조합을 사용한다.

## 색상

| 역할 | 값 |
|---|---|
| 심볼 주황 | `#E88942` |
| 남색 본문·워드마크 | `#26364A` |
| 배경 | `#FFF8EF` |
| 주요 행동·강조 글자 | `#AD4A19` |
| 주요 행동 hover | `#893A14` |
| 선택 배경 | `#FAEDE2` |
| 피치 카드 | `#F8E4D4` |
| 보조 글자 | `#625E59` |

밝은 주황은 심볼과 장식에 사용한다. 작은 글자와 버튼 글자에는 사용하지 않는다. 보조 글자는 기존 제안보다 어둡게 조정해 피치 카드에서도 대비를 확보했다. 기존 삽화의 민트·하늘색은 보조색으로 유지한다.

## 금지 예시와 접근성

- 가로·세로 비율 변경, 기울이기, 외곽선·그림자·그라데이션 추가.
- `홍보잇다`의 철자 변경, 영문 대체, 글자 일부 생략.
- 복잡한 사진 위에 여백·배경 없이 로고를 직접 배치.
- 핵심 행동이나 성공·오류를 심볼 색만으로 표현.

React 컴포넌트의 대체 텍스트는 ‘홍보잇다’다. 홈 이동 버튼에는 ‘홍보잇다 홈’을 지정한다. 한글은 Noto Sans CJK KR Bold의 윤곽이며 외부 폰트를 다운로드하지 않아도 표시된다. 글꼴 저작권·SIL OFL은 `FONT-LICENSE.txt`에 보관한다.

생성 원본은 `design-assets/branding/concept-c/selected.png`, 탐색안은 `public/assets/branding/concepts/concept-c/`에 그대로 남긴다. 재생성은 프로젝트 루트에서 `node scripts/build-selected-brand.mjs`를 실행한다. 이 명령은 선택 로고와 favicon을 갱신한다.
