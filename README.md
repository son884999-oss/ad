# AI 홍보 스튜디오

팀원별 작업물을 먼저 모으는 저장소입니다. 각자 본인 폴더에 만든 파일을 올려 주세요.

## 현재 폴더 구성

저장소 루트에는 A~F 팀 폴더와 `ad_prototype`을 둡니다. `ad_prototype`은 Vercel에 연결된 React 앱입니다. Git 관리용 `.git`과 `.gitignore`는 유지합니다.

팀원 작업물을 하나로 합친 앱은 `ad_prototype`입니다. 실행 방법, AI 키(`.env.local`) 설정, 팀 모듈 통합 현황은 [ad_prototype/README.md](ad_prototype/README.md)를 봅니다.

- **문서는 [ad_prototype/docs/README.md](ad_prototype/docs/README.md)부터** — 지금 상태·규칙·설치·배포 (문서 5개)
- 결정과 이력: [ad_prototype/docs/결정과_이력.md](ad_prototype/docs/결정과_이력.md) · 발표 준비: [ad_prototype/docs/발표준비/홍보잇다_PC이어가기_1022.md](ad_prototype/docs/발표준비/홍보잇다_PC이어가기_1022.md)
- 시각 에셋(로고·일러스트·글꼴): `ad_prototype/design-assets/`, 앱에서 쓰는 사진은 `ad_prototype/public/assets/`

| 구분 | 담당자 | 작업 |
| --- | --- | --- |
| A | 손용범 | UI/UX 화면 설계(기본·쉬운 화면, 결과 탭), 모듈 통합, 배포 |
| B | 이창훈 | AI 홍보 글 규칙(채널별 글, 금지어, 문구 후보, 영상용 짧은 제목) |
| C | 김만복 | 제품 정보 입력 항목·글자 수 제한, 입력 화면 |
| D | 고혜숙 | 포스터 렌더러(크기·배치·색, 파일 이름 규칙) |
| E | 이채원 | 영상 연출 규칙, 장면 프롬프트, 업종별 연출 방향 |
| F | 육성준 | QA 피드백, 결과 화면 개선 요청, 사용자 관점 점검 |

## 작업물 올리기

1. 저장소 초대를 수락합니다.
2. 본인 이름의 폴더를 열고 **Add file → Upload files**로 작업 파일을 올립니다.
3. 작업물 실행 방법과 필요한 환경변수 이름을 본인 폴더의 `README.md`에 적습니다.
4. API 키, 비밀번호, `.env` 파일은 올리지 않습니다.

각 폴더의 `.gitkeep` 파일은 빈 폴더를 GitHub에 표시하기 위한 파일입니다. 작업물을 올린 후 삭제해도 됩니다.
