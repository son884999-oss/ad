Claude Haiku 4 (기관 COPA)→Gemini 무료 키→Gemini 유료 키 (일 500원 한도)→내장 기본 문구 (동일 금지어 규칙)
사진 분석과 홍보 문구 모두 같은 순서를 따르며, 모든 AI가 실패하더라도 결과물은 생성됩니다.

"AI 활용" 표시 (인공지능기본법 제31조, 기관 권고에 따라 보수적 적용)

AI 생성 문구 또는 AI 배경이 결과물에 포함되면 포스터와 영상에 "AI 활용" 표시 1개를 삽입합니다. AI가 관여하지 않은 경우에는 표시하지 않습니다. 표시 기준은 내용의 AI 생성 여부이며, 디자인을 AI가 수행했다는 의미는 아닙니다.

보안 및 개인정보

  • AI 키·관리자 키는 서버 환경 변수에만 보관하며, 브라우저에는 공개용 키(Supabase) 1개만 존재합니다.
  • 가입 시 [필수] 만 14세 이상 확인 및 개인정보 수집·이용 동의를 받고, 처리방침을 제공합니다.
  • 파일은 비공개로 저장되어 7일 유효 서명 URL로만 접근할 수 있으며, 탈퇴 시 계정·기록·파일을 일괄 삭제합니다.

작성 기준일 2026-10-19

서비스 처리 흐름 1회 이용 기준, 소요 시간은 실측값

  1. 접속 — Vercel에서 화면 파일(React 단일 페이지 앱)을 제공합니다. 별도 설치 없이 모바일 브라우저에서 이용할 수 있습니다.
  2. 사진 등록 — 브라우저에서 흐림·노출·해상도를 즉시 점검하고, 사진 분석을 비동기로 요청합니다 (수 초 후 입력 항목이 자동 완성됩니다).
  3. 배경 변환 선택 — "바꾸기" 선택 시 광고 배경 생성을 즉시 요청합니다. 15~30초가 소요되나 정보 입력과 병행되어 대기 시간이 거의 체감되지 않습니다.
  4. 정보 입력 — 직접 입력하거나 음성으로 입력합니다. 사진을 변경하면 배경 변환 여부를 다시 확인합니다.
  5. 생성 — 서버에서 홍보 문구를 생성합니다 (최대 11초, 초과 시 대체 순서·기본 문구 적용). 동시에 브라우저에서 포스터를 즉시 렌더링하고, 6초 영상을 실시간 녹화한 뒤 MP4로 변환합니다.
  6. 결과 확인 — 변환/원본 사진 선택, 포스터 비율·배치·색상 변경(재생성 비용 없음), 문구 복사, 파일 저장·공유를 할 수 있습니다.
  7. 보관 — 회원은 생성 완료 후 기록과 사진·포스터·영상을 서버에 저장합니다. 다른 기기에서는 원본 사진을 내려받아 동일하게 재구성합니다.

A. 특급 영상 생성형 AI 기반 동영상

결과 화면 "특급 영상으로 다시 만들기"→서버에서 Higgsfield로 요청→Kling 2.5 Turbo가 사진 기반 5초 영상 생성→상태 조회(1~3분)→브라우저에서 자막·음향 후편집
구현 현황
서버 함수(api/video-start·status·cancel), 시연 코드 등록 단말만 허용, 일 5회 상한, 시작 전 취소·환불 처리
잔여 과제
영상 품질 개선(불필요한 글자 생성, 제품 가림·축소) 위한 프롬프트 보완 → 예시 영상 제작 후 팀 공유
비용
1회 약 300~450원(5초). 일 5회 상한 기준 일 최대 약 2,250원. 현 예산 범위 밖으로 별도 예산 필요

B. 결제 (이용권) 시스템 설계안

이용권 구매→PG 결제창 (토스페이먼츠·포트원)→서버에서 PG사에 금액·주문번호 재검증→Supabase 이용권 테이블 (본인만)→사용 시 차감→AI 실패 시 복구
1단계
테스트 모드: 사업자 등록 없이 테스트 키로 연동, 실제 금전 거래 없음. 결제창·승인·실패·취소 흐름은 실결제와 동일. 개발 약 1일, 비용 0원. 화면에 "테스트 결제" 명시
2단계
실결제: 사업자등록·통신판매업 신고·PG 가맹 심사, 이용약관·환불 규정·사업자 정보 표기, 디지털 콘텐츠 청약철회 제한 고지. 키 교체만으로 전환 가능. 카드 수수료는 계약 조건에 따름
결정 사항
판매 대상(배경 변환 이용권, 특급 영상), 가격(원가 및 실패율 반영), 도입 시점(QA 전/후)
