- HWP → HWPX conversion
- HWPX → HWP conversion

**Input → Action → Processing → Result → Download / Next Step**

Users should never need to ask:

- Where do I start?
- What information should I enter?
- Which button should I press?
- Is the process working?
- Where is my result?

Use progressive disclosure for advanced settings.
