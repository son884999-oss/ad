# A 구현 현황 및 통합 인계 — 2026-10-02

## 기준 문서

로컬의 「홍보 잇다_기획서_수정본.pdf」(2쪽), 「홍보잇다_개발 계획서.pdf」(7쪽), 「홍보잇다_프롬포트.pdf」(7쪽)를 전체 확인했다. 원본 PDF나 타 팀원의 역할/공통 규격은 변경하지 않았다.

## 완료 범위

- `video.mjs`: `imageUrl + videoPrompt`를 받아 Higgsfield Kling 2.5 Turbo Standard Image-to-Video를 호출하고 `videoUrl`과 상태를 반환하는 서버 모듈. 기존 `prompt` 입력도 호환. 기본 10초, 선택 5/10초.
- 쵸이셀 제품 사진과 수동 샘플 프롬프트로 실제 유료 5초 생성 및 로컬 다운로드를 실행했다. 실제 API 성공 이력이며 mock만으로 확인한 것은 아니다. 이번 GitHub 게시를 위해 새 유료 요청은 하지 않는다.
- `kling-ad.mjs`: 로컬 제품 사진 업로드, 5초 생성, 원본 저장, 문구 합성. 원본이 존재하면 유료 생성 대신 합성만 수행. 클라이언트 재시도 0회. 완성본 덮어쓰기 방지.
- `sample-ad.json`, `sample-push.json`: B/E 미연결 상태의 수동 샘플. AI 자동 문구/프롬프트 생성 결과로 오해하지 말 것.
- `compose-*.mjs`: FFmpeg 기반 한글 합성 시안. 문구/폰트/색/그림자/등장 시점, 별도 브랜드컷 편집 실험. `compose-editorial.mjs`는 직접 합성한 효과음 포함.
- `assets/fonts`: 고운돋움 및 OFL 라이선스. 나머지 일부 템플릿은 Windows 맑은 고딕·바탕 의존.

## 문서 목표와의 차이 / 미완료

1. 전체 입력 웹앱, B/C/D/E/F 실제 연결, 통합 상태관리·수동 재시도 UI, Vercel 배포는 미완료다. A 전체 완료로 표시하지 않는다.
2. 현재 영상은 정사각형 원본 및 1080×1080 합성 실험이다. 문서 목표 720p/9:16 세로형 충족을 검증한 결과가 아니다. 확대 출력은 원본 디테일 향상을 의미하지 않는다.
3. 한글·효과음·자동 컷 편집은 문서상 MVP 제외인 확장 실험이다. 사용자의 추가 요청으로 시험했으나 필수 MVP 규격을 임의로 바꾸지는 않는다.
4. 광고 미감은 사용자가 만족하지 않은 상태이며 **디자인 확정/상용 품질 승인 아님**. 글꼴 교체·그림자만으로 광고 완성도가 확보되지는 않았다.
5. 텍스트 위치/길이/타이밍은 템플릿별 제약이 있다. 임의 상품의 위치 검출·자동 줄바꿈·제품 가림 방지·범용 품질 검수는 미완료.
6. 합성 결과는 로컬 `videoPath`다. 원본 제공자 URL과 다르며, 최종 합성본을 스토리지에 올려 F에 `videoUrl`로 전달하는 작업이 필요하다.
7. 사진 업로드는 현재 Higgsfield 업로드 경로의 로컬 실험이며, C의 공용 ImageKit/대체 스토리지 연결을 확정한 것이 아니다.
8. 로컬 파일명/경로는 쵸이셀 데모 기준이다. 저장소 밖의 제품 사진과 원본 MP4는 Git에 포함하지 않는다. 다른 개발자는 해당 자산을 직접 준비하거나 `generate`에 접근 가능한 HTTPS 사진 URL을 전달한다.
9. 문서상 제품 설명은 필수다. 사진+상품명만으로 생성하는 UX는 논의 사항이며 공통 입력 규격을 변경하지 않았다.

## 모듈 연결 인계

- C → A: `imageUrl` (외부 접근 가능한 HTTPS URL).
- E → A: `videoPrompt`. E는 제품 정보·사진을 분석하고 연출 프롬프트를 작성하는 시스템을 담당. A의 샘플 문장을 E 자동 생성으로 교체한다.
- B → F: 기존 규격 `promoText` 유지. 영상용 짧은 카피로의 변환은 별도 협의 필요. 현재 합성기의 `headline/brand/productLine`은 A 내부 샘플 필드이지 공통 규격 확정이 아니다.
- A → F: 영상 모듈 성공 시 `videoUrl`, 실패 시 상태와 안전한 `errorMessage`. 합성 경로 선택 시 최종 파일 업로드가 추가로 필요하다.
- 서버 환경: `HF_CREDENTIALS`를 런타임에서만 로딩. `.env.local`은 Git 제외. Node.js, pnpm, FFmpeg(libass/libx264), 템플릿 글꼴 필요.

## 검증과 남은 위험

- `pnpm check`, `pnpm test`로 문법/타입 및 mock 테스트 확인. 실제 생성·합성은 이전 로컬 실행과 프레임/디코딩 검사로 별도 확인했다.
- 배포 서버의 FFmpeg 실행 가능성, 작업 시간 제한, 비동기 작업 큐, 비용 한도, 동시 요청/중복 과금 방지, 다운로드 실패 후 재개는 통합 전에 검증해야 한다. 로컬 데모의 원본 존재 검사는 운영용 멱등성 보장이 아니다.
- 과거 Seedance 예제(`index.ts`, `product-ad.ts`)는 보존용이다. 현재 기본 모델은 Kling이며 Seedance를 자동 실행하지 않는다.
- 작업 브랜치: `feature/a-video`. PR 검토 후 main 병합; 이번 게시에서 자동 병합하지 않는다.
