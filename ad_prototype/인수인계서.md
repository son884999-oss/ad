## 1. 가장 최근 사용자 요구

- 기존 화면과 기존 디자인 지침을 계속 보완하는 방식 대신, 레퍼런스 `10.12.b`의 1~4번 구조를 기준으로 새 화면을 제작한다.
- 사진뿐 아니라 사진의 자르는 모양, 폰트, 글자 크기, 줄바꿈, 여백, 카드·버튼·도형 크기까지 레퍼런스를 기준으로 맞춘다.
- 흰 배경을 유지한다. 먼저 레퍼런스의 초록색으로 제작하고 주황 계열 변경은 이후 작업으로 진행할 수 있다.
- 홈의 `홍보물 만들기`는 메뉴 선택창을 거치지 않고 `한 번에 완성`의 사진 등록 화면으로 바로 이동한다.
- `홍보물 이어 만들기`는 없앤다. 홈으로 돌아간 뒤 다시 만들기를 누르면 새 제작을 시작할 수 있어야 한다.
- 결과 화면의 `내용 다시 수정하기 / 새 홍보물 만들기`를 제거하고, 가로 중앙에 `홈으로` 버튼 하나를 둔다.
- `새로고침하거나 창을 닫기 전에 필요한 이미지·영상은 저장하고 문구는 복사해 주세요.` 안내는 삭제한다.
- 하단 내비게이션에 주요 정보와 버튼이 가리지 않아야 한다. 홈·메뉴·사진 등록·정보 입력의 핵심 정보를 한 화면에서 확인할 수 있게 한다.
- 기존 앱의 사진·장식 자산을 재사용하는 방식 대신 새 자산을 제작한다.
- 기존 프로젝트 MD 문서는 삭제하고 이번 작업 인수인계서를 새로 작성한다.
- 마지막 요청: 화면 작업을 멈추고 인수인계서를 먼저 전달한다. 추가 화면 수정이나 GitHub 게시를 진행하지 않는다.

## 6. 아직 완료되지 않은 부분

- **레퍼런스와 픽셀 단위로 동일하다는 검증은 하지 못했다.** 현재는 새로 구현한 레퍼런스 기반 화면이며, 글꼴 굵기·세부 여백·일부 아이콘·사진 경계가 완전히 같은지 추가 대조가 필요하다.
- 실제 `information-390.png`에서 **사진 변경 버튼의 아래쪽이 일부 잘리는 문제를 발견했다.** 마지막 사용자 요청으로 작업을 멈춰 아직 수정하지 않았다. `.information-photo`의 그리드 행 높이와 이미지 최소 크기를 우선 확인한다.
- 홈 제목에 프로그램으로 초점을 주면서 파란 포커스 테두리가 캡처에 나타난다. 실제 시연에서 이 표시를 어떻게 처리할지 검토가 필요하다. 입력 필드의 키보드 포커스 표시는 유지해야 한다.
- 사진 아래 경계는 현재 CSS 다각형이다. 레퍼런스와 같은 부드러운 곡선을 만들려면 SVG 곡선 마스크 등으로 정밀 조정해야 한다.
- 주황색 변경은 아직 하지 않았다. 현재 초록색으로 맞추는 단계이다.
- 이번 새 화면 검증에서는 실제 기기, 실제 음성 출력, 네이티브 공유 앱 호출, 새 화면에서의 영상 다운로드를 재검증하지 않았다.
- 내 홍보물 목록·플랜 화면은 새 CSS 연결 뒤 시각적으로 충분히 점검하지 않았다. 기존 클래스의 스타일 누락 여부를 확인해야 한다.
- 기존 검증 스크립트 일부는 이전 UI의 선택자·고정 내비게이션 방식·이어 만들기 동작을 전제로 하므로 현재 상태의 검증 기준으로 바로 사용하면 안 된다.
- 폰트는 현재 외부 Noto Sans KR URL에서 읽는다. 배포 환경에서 로딩 확인과 로컬 폰트 저장 여부 검토가 필요하다.
- 새 화면에서 `설정`과 읽어주기는 유지되지만 기존 설정·로그인 화면과 구성은 달라졌다. 마지막 사용자 요청으로 추가 정리는 중단했다.
