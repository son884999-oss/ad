## 수정 결과

| 발견한 문제 | 반영 |
| --- | --- |
| 크게 보기 원형이 포스터 문구를 가림 | 이미지·영상 조작을 공통 카드 헤더로 이동. 아이콘+글자, 134×52px, 네이비 배경으로 발견성과 터치 크기 유지. 사진·문구와 겹치지 않음 |
| 소개 입력 직후와 다시 수정하기에서 일부 줄이 잘림 | 소개·알리고 싶은 점의 최소 세 줄 공간 확보. 입력 내용과 화면 폭·글꼴 로딩에 맞춰 높이를 계산하며 전체 내용을 표시 |
| 문구 결과의 끝줄이 잘리고 내부 스크롤 필요 | 짧은 문구는 기존 결과 영역 최소 높이 유지. 긴 문구는 내용만큼 늘어나 페이지에서 전체를 읽도록 변경 |
| 사진 화면에서 같은 안내 반복 | 진행 단계는 유지하고 ‘사진을 올려 주세요’ 제목 하나로 정리. 반복 소제목 제거. 320×568에서도 업로드 버튼이 하단 메뉴 위에 온전히 보임 |
| 이전·사진 바꾸기·메뉴 닫기의 보조 스타일 편차 | 기존 `studio-secondary` 공통 표현 사용. 테두리·글자 색·모서리 통일 |
| 불완전한 추천 검색어 `#사용하` | 추천 불용어에 `사용하`, `있어`, `확인해`, `주세요`를 추가. 이전 재현 문장의 복사 결과에서 해당 검색어가 제외됨 |
| 한 번에 만들기의 결과 구성 선택 | 사진을 올린 뒤 가로 전체 폭의 기본 ‘둘 다’/‘포스터’/‘영상’ 단일 선택 표시. 기존 결과 구성 상태에 연결 |
| 제작 3단계의 미감·높이 | 같은 크기의 숫자·완료 표시, 짧은 단계 이름, 가는 연결선과 공통 둥근 바. 사진·설명·결과 순서 및 완료 단계로 돌아가기 유지 |

사진이 준비되면 반복 제목·형식 안내를 시각적으로 접고, 사진 높이를 실제 화면 높이에 맞춰 조절한다. **가이드 바 → 사진 → 토글 바 → 다음 단계**가 360×640·390×693과 더 작은320×568에서도 하단 메뉴 위에 모두 들어온다. 원본 파일은 조절하지 않는다. 가로로 아주 짧은 화면과 추가 오류 안내에는 필요한 페이지 스크롤을 허용한다.

| 선택 | 결과 탭 순서 | 처음 여는 결과 |
| --- | --- | --- |
| 둘 다 | 이미지 → 영상 → 문구 | 이미지 |
| 포스터 | 이미지 → 문구 | 이미지 |
| 영상 | 영상 → 문구 | 영상 |

문구는 항상 마지막 탭이며 모든 선택에 포함된다. 선택을 바꾸고 다시 제작해도 새 구성의 미디어가 먼저 열린다. 직접 문구 탭이나 내 홍보물의 문구 결과를 누르는 사용자의 행동은 유지한다.

공통 카드 제목과 확인용 예시 표식의 표현도 공유한다. 기본 로고·색상·서체·하단 메뉴·결과 탭·사진→설명→결과 순서와 상품명만 필수인 조건을 유지했다. 숨긴 결과 하위 기능은 복원하지 않았다.

이미지와 영상의 표시 프레임·정렬·저장 버튼 규격은 동일하다. 긴 문구에 한해서 높이가 늘어나므로 복사 버튼까지 페이지를 스크롤할 수 있다. 결과 내용을 읽기 위해 문구 칸과 페이지를 각각 스크롤해야 했던 부담을 줄이는 선택이다.

## 검증

- `pnpm build`, `pnpm exec tsc --noEmit`, `git diff --check`: 통과.
- `pnpm verify:submission`: 320×568, 360×640, 390×693, 390×844, 844×390, 1440×844 각각 일반·간편모드, 총12개 조합 통과.
- 세로형 휴대폰에서 네 요소의 순서·위치·하단 메뉴와의 간격을 실제 계산값과 캡처로 확인. 모바일·PC에서 세 선택의 정확한 탭 구성과 문구의 마지막 순서·미디어 초기 표시 확인.
- 사진 아이콘·텍스트 버튼에서 실제 파일 선택창, 상품명만 입력한 상태의 다음 단계 활성화, 긴 입력·문구 전체 표시, 보조 버튼 스타일, 결과 프레임·조작 버튼 비중첩 확인.
- 실제 PNG·영상 다운로드 및 전체 클립보드 복사 확인. 긴 소개로 수정 후에도 내용을 유지하고 결과 전체를 읽을 수 있음.
- `pnpm verify:results`: 14개 조합 통과. 결과 규격, 확대·재생, 키보드 탭, 복사 실패·재시도, 이미지·영상 저장, 준비 취소 확인.
- `pnpm verify:experts`: 390×844 간편모드의 상태·낭독·확대 끝부분·녹화 수명 검증 통과.
- 현재 모바일·PC의 실제 캡처를 시각적으로 확인했다. 이전 테스트 결과만으로 외관을 합격 처리하지 않았다.
- `copyFinalText`, `createPosterFile`, `createVideoFile` 본문은 기준 커밋과 정확히 동일하다. 영상 생성 API·출력 알고리즘·원본 이미지 해상도와 비율을 변경하지 않았다.

## 남은 확인

이번 검증은 로컬 Chromium과 체험용 생성 결과 기준이다. 외부 글꼴 접근 제한 때문에 같은 Noto Sans KR 계열의 로컬 QA 글꼴을 사용했다. 실제 Android/iOS의 글꼴·키보드·낭독과 실제 AI 생성 품질은 별도 확인이 필요하다. 추천 불용어 보완은 완전한 한국어 형태소 분석을 의미하지 않는다. 실제 사용자 만족도나 교수 최종 승인을 측정한 결과도 아니다.

이번 요청은 현재 GitHub 브랜치 반영이며 main 병합이나 Vercel 배포를 포함하지 않는다.
