## 1. 기획 배경과 사용자 문제

중소벤처기업부·소상공인시장진흥공단의 「2024년 기준 소상공인실태조사」 결과 발표에 따르면 디지털·스마트 기술을 활용하는 소상공인 비중은 **27.2%**다.[S1] 이는 다양한 디지털·스마트 기술의 활용 여부에 관한 지표이며, 홍보 도구만의 이용률이나 컴퓨터 사용능력을 뜻하지 않는다.

국회예산정책처 「소상공인 지원 재정사업 평가」는 소상공인시장진흥공단의 「2024년 소상공인 디지털 전환 실태조사」를 인용해, **디지털 기술(기기) 미도입 응답자의 미도입 이유 1순위 중 인력·지식 부재가 45.6%**로 가장 높았다고 설명한다.[S2] 이 비율의 분모는 전체 소상공인이 아니다. 최초 조사보고서의 조사방법 전체는 이번 작업에서 직접 검증하지 못했다.

두 자료는 서로 다른 조사다. 두 비율을 결합해 같은 고객군의 비중이나 서비스 수요를 산출하지 않는다. 이 자료들을 바탕으로 팀은 도구 제공과 함께 **도구를 활용하는 과정의 부담**을 고려할 필요가 있다고 해석했다. 이는 팀의 기획 판단이다.

## 2. 주요 사용자

**홍보 도구 사용에 부담을 느끼는 소상공인**을 핵심 사용자로 설정한다. 연령만으로 디지털 능력이나 홍보의 어려움을 판단하지 않는다.

다음 어려움은 사용자 조사에서 확인할 가설이다.

- 홍보문구 작성, 디자인, 영상 편집을 각각 배우고 수행하는 과정이 부담스럽다.
- 제품의 어떤 특징을 어떤 분위기로 보여줘야 할지 결정하기 어렵다.
- 결과물을 수정하거나 다시 생성할 때 시간·비용이 부담될 수 있다.

위 가설은 현재 통계가 직접 입증한 사용자 경험이 아니다.

## 3. 개발 목적과 기획 의도

**개발 목적:** 홍보 콘텐츠 제작 과정의 부담을 낮춰, 소상공인이 직접 홍보를 시작할 기회를 넓힌다.

**기획 의도:** 사용자가 제품 사진 1장과 필요한 정보를 바탕으로 포스터·10초 영상·홍보 글을 하나의 흐름에서 제작하고 활용하도록 돕는다. 여러 도구를 오가며 제품 정보를 반복 입력하는 부담을 줄이는 것이 목적이다. 큰 글씨·쉬운 말·음성 입력·듣기를 제공하는 **쉬운 화면**을 통해 도구 사용 부담도 고려한다.[S4] 이는 기존 기획서의 통합 제작 방향을 공유된 커밋의 팀 문서에 맞춰 구체화한 설명이다.

충남연구원은 「충청남도 소상공인 디지털전환 추진방안」에서 업체의 디지털전환 수준을 고려한 단계별 지원과 소상공인·소비자·지역 간 연결을 제안했다.[S3] 팀은 이를 참고해 **쉬운 제작 과정과 고객 연결**을 기획의 방향으로 삼았다. 보고서가 우리 서비스의 효과를 검증한 것은 아니다.

이 접근의 경쟁 서비스 대비 차별성은 이번 문서에서 확정하지 않는다. 경쟁 서비스 비교와 실제 사용자 검증이 추가로 필요하다.

## 4. 서비스 흐름과 기술의 역할

**사진 넣기 → 선택적 배경 변경 → 정보 입력·자동 채우기 → 포스터·10초 영상·홍보 글 → 확인·복사·저장·공유**

| 단계 | 공유된 커밋의 팀 문서 기준 | 확인할 기준 |
| --- | --- | --- |
| 입력 | 제품 사진을 올리고 정보를 입력. 자동 채우기를 눌렀을 때 AI가 사진을 분석. 기본·쉬운 화면 전환 제공 | 사용자가 입력 요구사항을 이해하는가 |
| 제작 | 포스터·10초 영상·홍보 글 제공. 배경 변경은 선택적으로 이용 | 제품의 특징이 결과물에 충실히 반영되는가 |
| 확인·활용 | 결과 확인 후 복사·저장·공유. 로그인하면 내 홍보물에 서버 저장 | 사용자가 도움 없이 결과물을 찾고 활용하는가 |

**기술의 역할:** AI는 사진 분석·홍보 글 작성·선택적인 배경 변경에 활용한다. 포스터와 기본 10초 영상은 브라우저 코드로 제작한다. 기본 영상을 외부 AI 영상 생성 API의 출력으로 설명하지 않는다.[S4]

위 내용은 해당 커밋의 팀 문서에서 확인한 구현 설명이다. 이번 작업에서 전체 소스 동작·실제 배포·사용자 테스트를 재검증한 것은 아니다. 초기 E 담당 모듈의 역할과 현재 통합 앱의 기본 영상 제작 방식을 구분한다.

## 5. 설계 원칙과 기대 효과

| 설계 원칙 | 기획에서 지킬 것 | 검증 방법 |
| --- | --- | --- |
| 쉬운 화면 | 큰 글씨·쉬운 말·말로 입력·듣기로 사용자의 입력과 이해를 지원 | 입력 중 막힘·질문·도움 요청 관찰 |
| 제품에 충실한 표현 | 제품 형태·색상·라벨을 보존하고 확인되지 않은 특성·효능을 만들지 않도록 검토 | 입력 사진·정보와 결과물 비교 |
| 활용 가능한 결과 | 결과를 확인하고 저장하는 과정까지 연결 | 홍보물 완성·저장 여부 관찰 |

기대 효과는 제작 진입 부담 완화와 홍보 기회 확대다. 아직 시간 절감률·매출 증가·폐업 감소를 확인한 성과로 제시하지 않는다. 초기 사용자 테스트에서는 과업 완료 여부, 소요시간, 도움 요청, 재생성 횟수와 이유를 기록한다. 목표 수치나 개선율은 측정 전 임의로 정하지 않는다.

“중기부 조사에서 2024년 기준 디지털·스마트 기술 활용 비중은 27.2%였습니다. 별도의 디지털 전환 조사에서는 기술 미도입 응답자의 미도입 이유 1순위로 인력과 지식 부족이 45.6%를 차지했습니다. 두 수치는 조사대상이 다릅니다. 우리는 이를 개발 배경으로 삼아, 도구를 제공하는 것과 함께 활용 과정의 부담을 낮추는 방향을 선택했습니다.”

“사용자는 제품 사진을 올리고 필요한 정보를 입력합니다. 자동 채우기를 누르면 AI가 사진을 분석해 입력을 돕습니다. AI는 홍보 글과 선택적인 배경 변경에 활용하고, 포스터와 10초 영상은 브라우저에서 제작합니다. 결과를 확인하고 복사·저장·공유하는 흐름입니다. 여러 제작 과정을 간단하게 이어주는 것이 핵심입니다.”

### 4장 — 홍보를 시작할 수 있도록. / 약 35초

“설계 기준은 쉬운 화면, 제품에 충실한 표현, 활용 가능한 결과물입니다. 큰 글씨와 쉬운 말, 음성 입력과 듣기로 사용을 돕습니다. 기대하는 변화는 제작 부담 완화와 홍보 기회 확대입니다. 실제 효과는 사용자가 홍보물을 완성하고 저장하는지, 시간이 얼마나 걸리고 어떤 도움이 필요한지 관찰해 확인하겠습니다.”

- **8장 S3:** 충남연구원 PDF 5쪽에서 전환 수준을 파악해야 한다는 문장과 체크리스트 점수에 맞는 사업을 고려한다는 문장을 각각 발췌했다. 두 문장 사이의 설명 생략을 표시하고, 같은 쪽의 단계별 정의·지원 제안을 표로 요약해 맥락을 보강했다.

8장에서 설명할 근거의 맥락은 다음과 같다. 아래는 직접 인용이 아닌 원문 요약이다.

| 사용자·업체의 상황 — 원문 요약 | 보고서가 제안한 지원 방향 — 원문 요약 |
| --- | --- |
| 도입 준비가 필요한 단계 | 기초 교육과 이용 상담, 현장 보조 등으로 시작을 지원 |
| 기술의 필요성은 알지만 활용이 낮은 단계 | 활용 지도, 결제 환경과 온라인 판매·배송 기반을 지원 |
| 스스로 기술을 활용하고 확장할 수 있는 단계 | 업종별 장비와 물류 체계, 데이터 활용 등으로 확장을 지원 |

보고서의 논지는 업체의 준비·활용 수준을 파악한 뒤 적합한 지원을 선택하자는 것이다. 팀은 이 관점을 쉬운 화면의 큰 글씨·쉬운 말·입력 도움과 연결한다. 이 연결은 팀의 해석이며, 보고서가 해당 화면이나 앱의 효과를 평가한 것은 아니다. 지역 조사에서 산출한 단계별 추정 비율은 전국 소상공인 비율로 혼동하지 않도록 추가하지 않았다.

원문 이미지는 다시 쓰거나 숫자·문구를 변경하지 않고 종횡비를 유지했다. 공식 PDF와 다운로드·발췌 기록은 `evidence/`에 함께 보관한다. 발표 본문 2~3장에서 해당 근거 원문 슬라이드 위치를 안내한다.
