## 다섯 방향의 차이

| 시안 | 디자인 의도·연결 표현 | 강점 | 보완점·권장 용도 |
|---|---|---|---|
| **A · 이음 리본** | 한 번 접힌 둥근 삼각 고리. 뫼비우스의 연속성과 하나의 관계를 압축 | 단단한 실루엣, 넓은 중앙 여백, 앱 아이콘·헤더의 균형 | 삼각 순환 표식과 구분되는 접힘 비율 정교화. **대표 심볼 우선 추천** |
| **B · 세 주체의 연결** | 두 주황 링크와 남색 중앙 링크. 소상공인↔플랫폼↔고객의 구조 | 세 주체의 관계 설명이 쉬움 | 체인·연동 아이콘에 가까워 독자성 약함. 플랫폼 소개·제휴·지원사업 자료에 적합 |
| **C · 오가는 흐름** | 넓은 왼쪽과 올라가는 오른쪽을 연결한 비대칭 무한 고리 | 친근한 흐름, 가로형 조합의 유연함 | 일반 무한대·잎의 연상이 남음. 작은 정사각 아이콘보다 캠페인·가로 매체에 적합 |
| **D · 글자로 잇다** | 한글 윤곽, ‘잇다’의 짙은 주황, 글자 아래를 잇는 획. 보조 심볼은 고리와 세로획 | 서비스명이 먼저 기억되고 한국어 판독성 유지 | 심볼만 보면 영문 a처럼 보일 수 있음. **한글 워드마크 중심의 보조 추천** |
| **E · 소식을 잇다** | 말풍선의 꼬리가 접힌 리본으로 이어짐 | 소식·소통 의미가 익숙하고 사각 영역 활용이 좋음 | 메신저·챗봇 연상 가능. 가게 소식·소통 중심 설명의 보조 후보 |

색상만 바꾼 다섯 변형이 아니다. 단일 고리 / 세 링크 / 비대칭 두 고리 / 한글 중심 / 말풍선이라는 다른 구조를 생성했다. 다만 C의 무한대, B의 체인, E의 말풍선은 일반적인 기호의 익숙함이 남는다는 점도 함께 제시한다.

## 한글 워드마크와 가독성

이미지 생성 모델에는 글자를 넣지 않았다. 공식 Noto Sans CJK KR Bold의 **홍·보·잇·다** 글리프를 읽고 실제 SVG path로 저장했다. 따라서 워드마크를 표시할 때 외부 폰트 다운로드나 기기에 설치된 글꼴에 의존하지 않는다. SVG의 제목·접근성 이름도 정확히 홍보잇다다.

A는 기본 자간, B는 조금 넓은 자간, C는 조밀한 자간, D는 색과 연결 획, E는 차분한 기본 조합을 사용한다. 완전히 새 글꼴을 개발한 것은 아니며, 검증된 글꼴을 바탕으로 로고의 자간·색·연결 획을 설계했다.

D의 첫 조합은 연결선이 받침에 가까워 보여, 실제 캡처 검토 후 글자 아래로 분리했다. 정확한 글자 윤곽을 유지하면서 읽기를 우선했다.

## 작은 크기·단색 검토

실제 Chromium 캡처를 열어 다섯 시안 모두 검토했다. 아래는 디자이너의 시각 판단이며 실제 시니어 사용자 인지 실험 결과가 아니다.

| 시안 | 32px | 96px·헤더 | 어두운 배경의 단색 표현 |
|---|---|---|---|
| A | 하나의 고리 형태가 유지됨. 접힘은 작은 색면으로 남음 | 접힘과 내부 여백이 명확 | 외곽은 안정적이나 접힌 면의 색 차이는 사라짐. 최종 단색판에 간격 처리 검토 |
| B | 세 고리는 보이나 교차부가 조밀 | 관계 설명이 쉬움 | 맞물림이 덩어리처럼 읽히므로 교차 간격 보정 필요 |
| C | 가로 실루엣은 남지만 교차선이 약함 | 가로 배치에서 더 자연스러움 | 두 고리는 유지되나 작은 교차 구분은 약함 |
| D | 큰 고리·세로획은 선명하나 영문자 연상 | 한글 이름 중심에서 장점. 워드마크는 가로 160px 이상 권장 | 글자는 잘 읽힘. 별도 연결 획의 여백 유지 필요 |
| E | 말풍선 형태는 읽히지만 접힘은 작음 | 소통의 의미가 빠르게 보임 | 일반 말풍선과 비슷해지는 한계가 뚜렷함 |

최종 승인을 받으면 선택 후보에 대해서만 16/24/32px 광학 보정, 단색판의 접힘·틈 처리, 완전한 벡터 경로와 안전 여백을 제작한다. 탐색 단계에서 모든 후보의 대규모 파생 라이브러리를 생산하지 않았다.

## 주황 중심 팔레트 제안

| 색 | 값 | 역할·이유 |
|---|---|---|
| 따뜻한 주황 | `#E88942` | 심볼·강조 면. 소상공인 서비스의 온기를 표현 |
| 짙은 남색 | `#26364A` | 한글 로고·본문. 주황의 활기를 안정적으로 받침 |
| 따뜻한 아이보리 | `#FFF8EF` | 밝고 편안한 배경 |
| 부드러운 피치 | `#F8E4D4` | 구획·보조 안내 면 |
| 따뜻한 회색 | `#706D68` | 차분한 보조 설명 |
| 구운 주황 | `#AD4A19` | 읽는 글자와 주요 버튼 제안. 밝은 주황의 대비 한계 보완 |

실제 계산한 대비는 남색/아이보리 **11.66:1**, 회색/아이보리 **4.89:1**, 흰색/구운 주황 **5.57:1**, 구운 주황/아이보리 **5.28:1**이다. 밝은 주황/아이보리는 **2.46:1**이므로 작은 본문·중요 조작 글자에 사용하지 않는다. 이는 주요 조합 계산이며 전체 WCAG 인증이 아니다.

생성 raster에는 미세한 색 변화가 남아 있다. 표의 HEX는 최종 색상 규격 제안이며 모든 생성 픽셀이 그 값과 동일하다고 주장하지 않는다. 승인 후 벡터 정리에서 정확한 단색 면으로 고정한다. 기존 서비스 토큰에는 이번 팔레트를 적용하지 않았다.

## 세 관점의 평가

| 시안 | 시니어 UX | 프론트엔드 | 브랜드 디자인 |
|---|---|---|---|
| A | 큰 고리 한 개라 구별하기 쉬움. 이름을 함께 소개해야 의미가 연결됨 | 소형 재현성이 가장 안정적. 두 면의 순수 SVG와 단색 틈 처리 권장 | 뫼비우스 의미와 단정함의 균형이 가장 좋음 |
| B | 익숙한 링크지만 세 요소를 읽는 부담 | 교차부 최소 간격·소형판 필요 | 플랫폼 관계는 잘 표현하나 일반 연동 기호와 차별화 필요 |
| C | 익숙한 무한대 흐름. 작은 정사각에서는 덜 두드러짐 | 가로 비례의 광학 보정 필요 | 역동적이지만 일반 무한대·환경 기호 연상이 약점 |
| D | 정확한 한글이 먼저 읽힘 | 실제 글리프 path라 표시 안정적. 연결 획의 안전 여백 필요 | 이름의 개성을 키우는 후보. 보조 심볼의 영문 연상은 약점 |
| E | 말풍선을 빠르게 알아보지만 채팅 기능을 기대할 수 있음 | 32px 꼬리·접힘 간격 확인 필요 | 소식 전달에는 적합하나 챗봇을 피하려는 방향에서는 후순위 |

세 역할로 자체 검토했으며 외부 전문가·독립 에이전트·사용자 조사 결과로 표시하지 않는다. **A를 대표 심볼 후보, D를 한글 중심 후보로 추천**한다. A와 D를 결합한 새 안을 확정하거나 적용한 것은 아니다. 원하면 승인 이후 조합을 별도로 탐색할 수 있다.

## 실제 제작 파일

각 `public/assets/branding/concepts/concept-a/`부터 `concept-e/`에는 다음 세 파일이 있다.

| 파일 | 내용 |
|---|---|
| `symbol.webp` | 512×512 생성 심볼. 투명 여백 정리·축소, alpha 유지 |
| `wordmark.svg` | 정확한 홍보잇다 글리프와 시안별 처리. 실제 벡터 윤곽 |
| `horizontal.svg` | raster 심볼을 내장한 가로 조합. **혼합 SVG**이며 완전한 벡터 로고가 아님 |

심볼 파일 용량: A **26,118**, B **28,130**, C **25,202**, D **28,372**, E **19,088 bytes**. 가로 조합은 파일 하나만으로 열 수 있도록 심볼을 내장했다.

원본은 `design-assets/branding/concept-*/selected.png`에 있고 A 최초 생성은 `concept-a/original-v1.png`에 추가 보존했다. PNG 원본을 삭제하거나 기존 서비스 브랜드 에셋을 덮어쓰지 않았다. C 원본 구석에는 alpha 1/255 수준의 미세 잔여값이 있어 완전히 이진화된 투명 마스크라고 표현하지 않는다.

새 파일 묶음:

- `public/brand-review/index.html`, `review.css`, `review.js`, `comparison.png`: 독립 HTML 비교 자료.
- `public/assets/branding/concepts/concept-{a,b,c,d,e}/`: 후보별 3개 파일.
- `public/assets/branding/concepts/manifest.json`, `FONT-LICENSE.txt`: 파일·출처 정보.
- `design-assets/branding/`: 생성 원본, 프롬프트, 기존 파일 보존 기준, 글꼴과 제작 도구.
- `scripts/build-brand-concepts.mjs`: 축소·워드마크 윤곽·가로 조합 재생성.
- `scripts/verify-brand-concepts.mjs`: 표시·한글·대비·기존 기능 검증.
- `PHASE4A_BRAND_REVIEW.md`: 이 보고서.

내장 `image_gen`으로 서로 다른 심볼 5종과 A의 보정 1회를 실제 생성했다. 생성 실패를 텍스트 제안으로 대체하지 않았다. 한글 윤곽 제작에는 `opentype.js` 2.0.0을 `design-assets/branding/tooling/`에만 설치했다. 앱의 package.json·lockfile·runtime 의존성은 바꾸지 않았다.

글꼴은 [Noto CJK 공식 저장소](https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/Korean)의 Noto Sans CJK KR Bold를 사용했고 [동일 저장소의 SIL OFL](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE)을 보관했다. 저작권·버전 정보는 `design-assets/branding/fonts/font-info.json`에 있다. 글리프 윤곽 변환은 [opentype.js 공식 문서](https://github.com/opentypejs/opentype.js)의 OTF 파싱·path 기능을 사용했다. 타사 로고나 일러스트를 복제하지 않았으며 별도 상표 유사성 조사를 완료했다고 주장하지 않는다.

## 검증 결과

- `node scripts/verify-brand-concepts.mjs` **통과**: 5개 시안, 320/375/390/430/768/1024/1440px, 가로 넘침 없음, 이미지 누락 없음, 1440px의 5열 비교, 실제 32/96px 표시, 문서 내 이동.
- 같은 검사에서 5개 워드마크와 가로 조합의 네 글리프 순서·접근성 이름·외부 폰트 비의존 확인, 주요 글자 대비 통과.
- 시작 시 기록한 기존 **31개 파일의 SHA-256 일치**: 서비스 소스·기존 삽화·favicon·주요 설정·지침 보존.
- 기존 서비스에서 사진 입력 → 설명 → 결과 3개 → PNG 다운로드 실제 브라우저 점검 **통과**.
- `npm run build`, TypeScript `--noEmit` **통과**.
- 실제 비교 이미지와 A–E 상세 캡처를 열어 밝은/어두운 배경·작은 심볼·한글을 검토했다. D의 받침 여백을 수정 후 다시 캡처·검증했다.
- 상세 기록은 `ui-review/phase4a/verification.json`, 캡처는 같은 폴더다. 실물 휴대전화나 시니어 인지 실험을 수행한 것은 아니다.

Vite의 public 정적 문서는 `/brand-review/index.html`이라는 명시 경로로 연다. 기존 홈페이지 라우팅을 바꾸지 않았다. 실행 중인 서버를 먼저 확인했으며 중단되어 있을 때만 동일 포트의 단일 서버를 다시 시작했다.

## 승인 후 Phase 4-B 제안

1. **후보 결정**: A–E 중 최종 탐색 방향, 심볼과 한글 중 무엇을 우선할지 선택한다.
2. **선택 후보만 정교화**: 순수 SVG 심볼, 정확한 단색·반전판, 16/24/32px 광학 보정, 최소 크기·안전 여백·사용 금지 예시를 확정한다.
3. **한글 조합 확정**: 정확한 이름, 자간, 심볼 대비 글자 비율을 결정한다. D 연결 획은 읽기를 우선하며 필요하면 작은 크기에서 생략하는 규칙을 만든다.
4. **제한된 UI 적용**: 승인된 로고·favicon·metadata 이미지·핵심 색상부터 적용하고 대비·첫 행동·기존 흐름을 회귀 확인한다.
5. **후속 일러스트**: 결과물·작업 화면 → 매장·플랫폼 환경 → 작은 보조 인물 순으로 구성한다. 인물이 필요하면 약 25–45세의 현대적인 성인을 사용한다. 접근성은 큰 글씨·명확한 조작으로 해결하며 고령 인물을 주인공으로 삼지 않는다.

**최종 로고 선택과 서비스 적용은 사용자 승인 후 진행한다.** 이는 이번 Phase 4-A 첨부 요청의 명시적인 경계다. 현재 5개 후보 제시까지만 완료했고, 기존 로고 교체·전체 재브랜딩·Phase 4-B 대량 제작·외부 배포는 수행하지 않았다.
