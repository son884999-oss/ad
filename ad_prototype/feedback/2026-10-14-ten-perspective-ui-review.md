## 실제 교차 토론

토론안 A–D에 대한 응답을 요약했다. 아래는 AI 검토자의 조건·반론 기록이며 사람의 찬성률이나 통계가 아니다.

| 관점 | A · 가림 | B · 상태·낭독 | C · 글자·이름 | D · 보관 안내 |
| --- | --- | --- | --- | --- |
| 일관성 | 찬성 | 찬성 | 조건부 | 조건부 |
| 시각 디자인 | 찬성 | 찬성 | 조건부 | 조건부 |
| 타이포그래피 | 찬성 | 조건부 | 찬성 | 찬성 |
| 시인성 | 조건부 | 찬성 | 찬성 | 찬성 |
| 상호작용 | 찬성 | 찬성 | 찬성 | 조건부 |
| 접근성 | 찬성 | 찬성 | 조건부 | 조건부 |

| 정보구조 | 찬성 | 조건부 | 찬성 | 찬성 |

- **A:** 원형 버튼을 줄이거나 z-index 경쟁을 늘리는 안보다, 짧은 화면의 저장바 고정을 해제하고 확대 끝 스크롤 공간을 확보하는 안을 선택. 저장 버튼이 항상 화면에 머무르지 않는 비용은 남지만 스크롤해 정상 접근 가능함을 확인.
- **B:** 작업 상태를 부모로 승격해 배경 준비를 유지하는 대안도 타당하다. 현재 범위에서는 단계·상품명 변경·화면 종료 시 준비를 취소하고, 준비 중에 이동 취소 정책을 안내하는 안을 선택. 결과 탭 전환은 파일 준비를 취소하지 않고 낭독만 중단.
- **C:** 모든 텍스트를 키우는 안보다 필수 조건·완료/오류·수정·보관 안내에 한정. 한국어 어절을 보존하되 긴 영문·URL에는 강제 줄바꿈을 허용. 눈에 보이는 이름과 음성·접근성 이름을 공유.
- **D:** 각 카드 반복이나 닫기 경고창 대신 공통 하단에서 한 번 안내. 요청한 저장·복사 상태와 현재 제공되는 종류에 따라 불필요한 안내를 줄이고, 기록 화면의 기존 문장도 교정.

## 글자·버튼·폰트 확인

아래 단위는 CSS px다. OS 실제 물리 크기나 저시력 사용자의 읽기 속도를 측정한 값은 아니다.

| 항목 | 일반 모드 | 간편모드 | 판단 |
| --- | --- | --- | --- |
| 상품명 입력·소개·알리고 싶은 점 | 18px | 22px | 기존 역할별 크기 유지 |
| 필수 조건·결과 수정·완료/오류·보관 핵심 안내 | 16px 기반 | 18px·행간1.6 | 간편모드 핵심 안내 보강 |
| 문구 결과 | 19px | 22px·행간1.6 | 기존 문서 표현 유지 |
| 저장·복사 주 행동 | 글자20px, 높이52px 이상 | 동일 | 세 결과 위치·스타일 공통 |
| 확대·재생·일시 정지 | 글자18px, 104×104px | 동일 | 크기 유지, 전체 원·아이콘·라벨 가림 검사 |
| 사진 바꾸기 | 글자18px, 높이44px | 동일 | 단계별 같은 스타일 유지 |
| 폰트 | Noto Sans KR | Noto Sans KR | 기존 기본 서체·가변 굵기 유지. Apple SD Gothic Neo → Malgun Gothic → sans-serif 대체 경로 |

기본 서체를 새로운 디자인 취향으로 교체하지 않았다. 테스트 환경에서는 외부 폰트 접근 제한 때문에 같은 Noto Sans KR 계열의 로컬 QA 글꼴을 주입해 한글 렌더링을 확인했다. computed `font-family`는 지정된 스택이며, 각 OS에서 실제 선택되는 대체 글꼴과 원격 폰트 로딩 성공을 증명하지 않는다.

## 검증

- `pnpm build`, `pnpm exec tsc --noEmit`, `git diff --check`: 통과.
- `pnpm verify:experts`: 20개 화면 조합 통과. 원형 중심과 반지름0.75 지점8곳·라벨의 전체 노출, 폰트/글자/버튼 계산값, 확대 끝 내용, 화면/음성 일치 검증.
- 실제 recorder·파일 이벤트로 준비→홈, 준비→이름만 수정, 취소→지연 디코드→재시도를 확인. 녹화 track 종료, 이전 다운로드 억제, 새 다운로드 단1회 및 실제 파일 크기 확인.
- 모의 음성 엔진으로 재생/준비 상태 안내·탭 변경 취소·늦은 낭독 억제·현재 포스터/문구 내용 확인. 실제 음성 품질은 검증하지 않음.
- 기존 통합 검사20개 화면, 결과 회귀14개 화면, 6회차×3개 화면 검사 모두 통과.
- `copyFinalText`, `createPosterFile`, `createVideoFile` 함수 본문은 기준 커밋과 동일. API·출력 파일 생성 알고리즘·원본 해상도/비율 유지. UI 수명·접근성·표시 규칙을 보완.

최종 음성 상태 표현을 보완한 후 해당 모바일 과업을 다시 확인했다. 과업 검사 개수를 더해 참가자 수나 만족도 점수로 표현하지 않는다.

## 유지·보류·남은 검증

- 유지: 사진→설명→결과, 하단 내비게이션, 상단 읽어주기와 결과 탭, 원형 큰 조작, 저장·복사의 정확한 동사, 공식 로고·주황/아이보리/네이비, 상품명만 필수, 숨긴 하위 기능·삭제 안내 미노출.
- 보류: 기본 미디어 버튼을 밖으로 분리하거나 축소하는 대안, 카드 제목 삭제, 활성 내비게이션 표식 강화, 검정 이전 버튼/녹색 표식 재색칠. 현재 근거가 약하거나 발견성·구조 회귀 비용이 있어 적용하지 않음.
- 실제 참가자 검증: 처음 본 사람이 버튼을 찾는지, 가져오기 뜻을 이해하는지, 파일을 다시 찾고 문구를 붙여넣는지, 편집·취소 정책을 예상하는지. 실제 발언·시간·도움 제공 여부는 미측정.
- 실제 Android/iOS의 폰트·TalkBack/VoiceOver·가상 키보드·OS 다운로드 위치·야외 시인성은 남아 있음.
- 영상은 기존 사진 움직임 예시이며 저장 파일의 실제 플레이어가 아님. 실제 AI API의 품질·지연은 검증하지 않음. 기록의 장기 보관 기능도 추가하지 않음.
