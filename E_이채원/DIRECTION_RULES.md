# 광고영상 연출 규칙 v0.1

입력 사진을 바탕으로 10초짜리 제품 광고용 영어 프롬프트를 만든다. 실제 영상 생성은 팀장 모듈에서 수행한다.

## 문장 순서

1. 콘셉트: 제품 중심의 간결한 광고 장면.
2. 분위기·조명: 사진과 어울리는 부드러운 조명. 선택값이 없으면 차분한 분위기.
3. 카메라: 10초의 연속 장면 하나, 작고 느린 push-in. 제품 전체와 라벨이 읽히는 구도.
4. 배경·강조: 사진의 배경·구도를 유지하고 보이는 디테일만 강조.
5. 보존: 형태·비율·색상·라벨 텍스트·로고 유지. 제품은 정지. 빠른 움직임, 컷 전환, 변형, 물체·문자 추가, 확인되지 않은 효과·효능 억제.

## 규칙 방식의 분류

제품명과 설명에서 키워드를 찾는다. 복수 분류가 겹치면 화장품 → 식품 → 생활용품 순서로 적용하며, 맞지 않으면 일반 제품을 사용한다. 영어 키워드는 단어 경계를 사용한다. 한국어는 부분 일치이므로 중의적인 입력은 잘못 분류될 수 있다.

| 분류 | 대표 키워드 | 콘셉트 | 사진에서 강조할 요소 |
| --- | --- | --- | --- |
| 식품 | 쿠키, 과자, 식품, 커피, cookie, food | 편안하고 친근한 제품 장면 | 보이는 표면 질감과 포장 |
| 화장품 | 세럼, 로션, 크림, 화장품, serum, skincare | 절제된 뷰티 제품 장면 | 보이는 용기 마감과 라벨 |
| 생활용품 | 머그, 컵, 텀블러, 생활용품, mug, household | 차분한 일상 제품 장면 | 보이는 윤곽과 표면 |
| 일반 | 분류 불명확 | 차분한 제품 중심 장면 | 보이는 윤곽과 디테일 |

`brandTone`은 고급·우아/premium, 밝음·활기/playful, 따뜻함/cozy를 각각 우아함·밝음·따뜻함으로 매핑한다. 복수 톤이면 이 순서대로 우선 적용하며 나머지는 차분함이다. 조명 변경은 사진과 일치하는 범위로 제한한다.

규칙 방식은 사진을 다운로드하거나 분석하지 않는다. 제품 정보는 분류에 사용하고, 원문 제품명·설명·효능·추가 지시를 프롬프트에 복사하지 않는다. `keySellingPoint`, `targetAudience`는 받아들이되 이 방식에서는 사용하지 않는다. 사진 확인 없이 강조점이나 인물·장면을 만들어내지 않기 위한 초안 선택이다.

## Gemini 방식

실제 이미지 바이트와 입력 정보를 함께 전달한다. AI에는 콘셉트·분위기/조명·배경/강조를 짧은 영어 JSON 필드로 요청하고 형식과 길이를 검사한다. 카메라 문장과 보존 문장은 서버 코드에서 공통으로 붙인다. 선택 강조점은 사진에서 확인될 때만 사용하고, 대상 고객은 분위기 조절에만 사용하도록 지시한다.

API 오류, 이미지 오류, 차단·잘린 응답, 빈 응답, 잘못된 JSON은 오류로 전달한다. 규칙 방식으로 자동 전환하지 않는다. AI 문장의 의미·사진 충실도는 형식 검사만으로 보장할 수 없으므로 실제 사진 검토가 필요하다. 영상 생성 모델이 모든 지시를 지키는지도 별도로 확인해야 한다.

## 통합 범위

프롬프트의 10초 표현은 연출 의도다. 실제 길이·비율·해상도는 팀장이 영상 API 설정과 결과로 검증한다. 프롬프트만으로 이를 보장하지 않는다. 증기·액체 흐름·효능 시연·회전·손이나 사람 등장 등 사진에서 확인되지 않는 표현은 기본 연출에 넣지 않는다.
