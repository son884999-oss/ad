# 홍보잇다 교수 상담 및 최신 체크리스트 검증

2026-10-13 · feature/UI-Screen · 로컬 UI/UX 프로토타입. 10/08 멘토링 및 10/12 교수 원본 체크리스트의 86개 식별자를 범위별로 검토했다. 전 항목을 실제 기능 합격으로 판정한 것이 아니다. 원본의 과거 완료 82개 집계는 수정하지 않고, 현재 검증·문서화·향후·미검증을 별도로 기록했다.

## 현재 화면과 이동

홈 및 하단 만들기 → 한 번에 만들기의 사진 등록 → 빈 설명 입력 → 결과의 이미지·영상·문구 탭 → 저장/복사. 메뉴에는 한 번에 만들기·이미지·영상·홍보 글 및 설정·플랜·로그인 시안을 통합했다. 하단 홈·만들기·내 홍보물·메뉴를 공통 사용한다. PC는 같은 모바일 구성을 최대 560px로 표시한다.

## 이번에 확인한 내용

- 로그인/회원가입 전환, 체험 로그인 후 홈, 구독/건당 플랜 선택 UI.
- 모든 제작 메뉴가 사진 등록 단계로 진입. 빈 설명과 필수 입력 시 결과 버튼 비활성.
- 최신 요청: 사진 단계의 홍보할 곳·결과 종류 선택과 고정 안내 바를 제거하고 본문에 ‘다음 단계’ 버튼만 제공한다. 설명 화면의 고객·검색어 추가 설정도 비활성화하여 렌더링하지 않는다. 핵심 설명을 적고 ‘결과 보기’를 누르면 바로 결과 탭으로 이동한다. 320/390/1440px에서 설정 부재·본문 버튼·가로 넘침을 재검증했다.
- 간편모드 22px/일반 18px. 읽기 준비 및 취소 상태만 검증했고 실제 음질은 확인하지 않았다.
- 결과 진입 시 탭 상단 57px, 읽어주기 바 하단 57px. 이미지 저장 버튼 하단 737px, 메뉴 상단 763px로 가림 없음(390×844).
- PNG 다운로드, 2배 확대, 영상 재생/정지 및 MP4 예시 다운로드, 표시 문구와 실제 클립보드 일치, 기록에서 영상 다시 열기.
- 최근 홈의 320/375/390/430/1440px 크기별 자료에서 가로 넘침 없음. 짧은 화면은 자연스러운 스크롤. 모든 기능을 모든 크기에서 반복한 것은 아님.
- 새 작업에서 기존 사진·설명 초기화, 되돌리기 삭제는 최신 사용자 요청. 단계 안의 이전 이동과 사진 변경은 별개로 유지.

## 향후 홈 계획 - 미구현

현재 중앙 커피 이미지 영역은 샘플 준비 후 **생성된 포스터·영상·홍보문구 카드가 순환하는 영역**으로 교체할 예정이다. 대표 만들기 버튼과 3단계 안내는 고정하고, 상세 가이드는 메뉴에 둔다. 카드 전환 속도·정지 버튼·영상 무음·동작 줄이기는 후속 논의다. 이번 업로드에서 순환을 구현하거나 샘플 품질이 완성됐다고 표시하지 않는다.

## 교수 상담 질문

1. 현재 상단 CTA + 하단 만들기의 직접 사진 진입을 유지해도 되는가? 원문의 하단 만들러 가기와 위치가 다르다.
2. 6번 이미지 카드는 제작 전 템플릿인가, 제작 후 결과 갤러리인가? 7번 썸네일은 영상 후보인가 장면인가? 8번 SNS/블로그/상세 설명은 동시 생성인가?
3. 중앙 순환 카드 홈의 방향과 상세 가이드의 메뉴 이동을 승인할 수 있는가? 실제 샘플 선택은 후속 검토다.

## 검증 한계와 향후 기능

실제 AI 이미지·영상 API, 인증/회원가입 서버, 결제·크레딧 차감, 영구 저장, 외부 자동 게시는 향후 기능이다. 휴대폰 실기기 키보드·iOS 안전 영역·시니어 사용자 이해도·음성 품질은 미검증이다. 요금·무료 횟수는 가안이며 교수 확정안이 아니다. 배포 사이트는 이번 로컬 브랜치와 동일 버전이라고 확인하지 않았다. 교수 최종 승인으로 표시하지 않는다.
