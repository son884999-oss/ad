# PC 화면 제로베이스 재설계 계획

작성일: 2026-10-15 · 브랜치: `feature/UI-Screen`

## 결정 사항

PC 화면(`html[data-layout=pc]`)은 현재 모바일 화면을 넓혀 맞춘 구조라 완성도에 한계가 있다.
그래서 **PC 화면은 처음부터 다시 설계한다.**

- **가져올 것:** 기능만 가져온다. 화면 흐름, 상태 관리, 생성·다운로드·공유 로직은 그대로 쓴다.
- **전부 바꿀 것:** 레이아웃, 에셋(이미지·일러스트·아이콘), 버튼과 컴포넌트 스타일
- **모바일 화면:** 이번 재설계 대상이 아니다. 지금 화면을 유지한다.

## 그때까지의 임시 상태

- 컴퓨터에서 열면 **개발자 옵션(휴대폰 화면 미리보기)이 기본으로 켜져** 있다. 미완성 PC 화면 대신 모바일 화면을 보여 주기 위해서다.
  - 위치: `src/DesktopStage.tsx`의 `storedView` 기본값
  - PC 화면이 완성되면 이 기본값을 `"mobile"`에서 `"auto"`로 되돌린다.
  - 메뉴 › 개발자 옵션, 또는 오른쪽 아래 `개발자 모드` 툴바(자동/모바일/PC)로 언제든 전환할 수 있다.
- 2026-10-15에 지금 PC 화면도 미감만 1차로 다듬었다(기능 변경 없음). 커밋 `792de6c`, `5664b92`
  - 재설계 전까지 버틸 수준으로 다듬은 것이다. 재설계 때는 이 PC 전용 규칙을 버린다.

## 재설계 때 반드시 유지할 기능

- 상단 메뉴: 홈 / 만들기 / 내 홍보물 / 메뉴, 글씨 크기 전환(기본·크게)
- 만들기 흐름: 사진 등록(선택·끌어다 놓기·예시) → 정보 입력(제품 이름 필수, 가게 이름, 홍보 분위기, 더 자세히 알려주기) → 만드는 중(진행률·취소) → 결과
- 결과: 이미지/영상/홍보 글 탭, 크게 보기, 재생, 다운로드, 공유하기, 복사하기, 홈으로
- 내 홍보물: 전체/이미지/영상/홍보 글 필터, 항목 열기
- 메뉴: 만들기 4종, 내 홍보물 보기, 구독·건당 플랜, 로그인 화면, 큰 글씨 화면, 개발자 옵션
- 큰 글씨(easy) 모드, 화면 설명 듣기, 키보드 이동·포커스 표시, 움직임 줄이기 설정 대응
- 개발자 모드 화면 전환 툴바(`DevToolbar`)

## 재설계 때 참고할 리뷰 결과 (2026-10-15)

- **글자 크기:** PC는 `--s`가 1로 고정되어 본문이 모바일과 같은 px로 나온다. PC는 본문·도움말 16px 이상, 입력 18px 이상을 기준으로 잡는다.
- **배경과 카드:** 흰 카드와 거의 흰 배경이 구분되지 않았다. 배경 톤과 카드 경계·그림자를 체계로 정한다.
- **보조 버튼과 업로드 영역:** 테두리 대비가 낮아(1.4~1.5:1) 비활성처럼 보였다.
- **결과 화면 오른쪽 열:** 비어 보였다. 동작 버튼을 하나의 패널로 묶는다.
- **기준선:** 제목과 본문의 왼쪽 시작선이 화면마다 달랐다. 그리드를 하나로 통일한다.

## 별도로 남은 일 (기능·마크업 수정이라 이번 범위에서 뺀 것)

- **포스터 제목 중복:** 제품 이름만 입력하면 포스터에 제목과 같은 문구가 한 번 더 찍힌다(`App.tsx`의 `mediaText`).
- **홍보 글이 너무 짧음:** 제품 이름만 입력하면 홍보 글이 이름 한 줄로 끝난다.
- **접근성 2.5.3(보이는 글자와 접근성 이름 불일치):** "크게" 버튼의 접근성 이름은 "큰 글씨 화면"이라 보이는 글자가 이름에 포함되지 않는다. 개발자 툴바의 "자동"·"모바일" 버튼도 같다.
- **본문 바로가기 링크:** 첫 포커스가 링크 뒤로 이동해서 Tab으로 닿지 않는다.
- **안 쓰는 CSS:** 실제로 불러오는 스타일은 `src/index.css`, `src/reference-ui.css` 둘뿐이다. 나머지 `src/*.css`는 재설계 때 정리한다.
