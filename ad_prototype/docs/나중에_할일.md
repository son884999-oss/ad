- 정할 것: 기능 고정 범위인지(사용자).

### [발표날제한] 발표 날 제한 풀기 (10-26 추가)
- 10-26부터 홍보물 1건에 글 호출이 3회(첫 채널 + 나머지 두 채널 미리 받기). 같은 와이파이는 주소 하나라 분당 20회(`api/promo-text.js perMinute`)에 3배 빨리 닿는다. 배경은 분당 3회. 발표 날만 둘 다 올리고 하루 유료 상한도 2,000~3,000원으로(위 1절). 날짜·금액은 사용자가 정한다.

### [실기기확인] 실제 폰에서만 확인되는 것
- WebCodecs 빠른 MP4 경로, 느린 기기 실시간 녹화가 10초보다 짧게 나오는 문제(헤드리스 약 6.7초), 음성 인식(크롬·삼성 인터넷), 카카오톡 인앱 브라우저, 안드로이드 저장이 갤러리로 가는지, 아이폰 저장 안내.
- 실제 AI의 짧은 문구 품질, 실제 배경 보정에서 재료가 바뀌는지(가짜 응답 투어의 "딸기"는 데모 사진 때문).

### [사진입력화면] 카메라/앨범 두 칸 → 하나로?
- 사용자 의견: 큰 칸 하나가 두 개로 나뉘어 보기 어렵다. **논의 후 결정.**
- 조사(web.dev·MDN·GOV.UK·Ontario): `input accept="image/*"` 하나면 OS가 카메라·앨범 선택창을 띄움. `capture`는 호환성 제한.
- A안(추천): 큰 버튼 하나 "사진 넣기 — 찍거나 앨범에서 고르세요". B안: 큰 [카메라로 찍기] + 작은 "앨범에서 고르기" 링크. iOS Safari·카카오톡 인앱은 실기기 확인.
