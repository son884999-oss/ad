- **Higgsfield 사용 내역 확인:** 10-16에 검증 스크립트 하나(`verify:ai`)가 영상 요청을 막지 않은 채 실제 키가 있는 개발 서버에서 2~3번 실행됐습니다. 영상이 최대 6건쯤 만들어졌을 수 있습니다(1건 약 $0.21~0.31). [콘솔](https://console.higgsfield.ai)의 사용 내역을 확인해 주세요. 지금은 스크립트를 고쳤고, `VIDEO_ENABLED` 스위치도 추가했습니다.
- **영상 단가 확인:** 코드 주석의 Kling 2.5 Turbo 단가($0.042/초)는 공개 자료로 확인되지 않았습니다. 5초에 $0.31이라는 자료도 있습니다. 실제 시험 전에 콘솔에서 확인합니다.
- **법적 의무(인공지능기본법 제31조, 2026-01-22 시행, 계도기간 1년 이상):** AI 생성물 표시의 최소 조치는 반영했습니다. 아래 "AI 표시 마무리"는 정식 서비스 전에 해야 합니다. 법률 자문은 아닙니다. [근거](https://view.asiae.co.kr/article/2026012112451263037)

## 2. 영상 (단계별)

1. **5초 실제 시험** (약 $0.21~0.31/편, `VIDEO_ENABLED=1` + `node scripts/live-video-test.mjs --yes-spend`)
   - 업종별로 3~4편을 만들어 제품 모양과 라벨이 유지되는지 확인합니다.
   - 결과 영상 주소에 `Access-Control-Allow-Origin` 헤더가 있는지 `curl -I`로 확인합니다. 3번 후편집이 가능한지가 여기에 달려 있습니다.
2. **음악 정책:** 직접 합성하거나 상업 이용이 확인된 곡만 `public/`에 두고, 라이선스 증빙을 보관합니다. CC BY-NC/ND는 쓸 수 없습니다. [근거](https://www.foximusic.com/blog/es/royalty-free-music-for-commercial-use-guide/)
3. **후편집(자막+배경음을 실제 AI 영상에 합성):** 브라우저에서 WebCodecs + [Mediabunny](https://mediabunny.dev/guide/introduction)를 1순위로 씁니다(서버 비용 0, 약 17kB).
   - CORS가 막혀 있으면 우리 API로 중계하거나 서버 FFmpeg로 바꿉니다.
   - 같은 엔진으로 예시 영상도 만들면 결과 형식이 하나로 통일됩니다.
   - 공수: M(2~4일)
4. **720p 이상 + 소리 포함 모델 A/B:** Wan 3.0 `generate_audio:true`를 1회 비교합니다. 생성 오디오보다 통제 가능한 배경음이 낫다는 판단이 기본입니다. [모델 목록](https://docs.higgsfield.ai/docs/models/video-generation)
5. **나중에:**
   - 서버 FFmpeg(Vercel, A_손용범 `compose-*.mjs` 재사용, Pro 요금제 권장) 또는 Shotstack(약 $0.30/분)
   - 깊이 맵 패럴랙스(모델 수십 MB)
