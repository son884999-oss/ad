# 홍보잇다 Phase 2 — 홍보 채널 전략
검토일: 2026-10-09. 순위와 난이도 평가는 공식 자료를 바탕으로 한 제품 설계 판단이며, 광고 성과를 보장하거나 이용자 통계를 추정한 결과가 아니다.

## 현재 구현에서 확인한 사실
기존 세 채널은 인스타그램(`instagram`), 엑스(`x`), 쓰레드(`threads`)다. `src/App.tsx`의 1단계 선택 버튼이 문구 템플릿, 포스터·영상 색상, 검색어 추천 개수를 바꿨다. 선택값은 작업 초안과 메모리 내 결과 기록에도 저장된다. 외부 계정 연결, OAuth, 게시 API, 예약 발행, 광고 집행은 구현되어 있지 않다. 버튼은 자동 게시 기능을 의미하지 않는다.

실제 작동하는 것은 브라우저의 사진 읽기, 규칙 기반 문구·검색어 예시, Canvas PNG 저장, MediaRecorder의 약 3초 MP4/WebM 생성, 클립보드 복사, 초안 되돌리기와 같은 창의 결과 복원이다. React·React DOM 외에 게시 플랫폼용 runtime SDK도 없다. 로그인·회원가입과 요금제는 체험 화면이다. 이 기능 경계를 유지했다.

## 기본 추천 순위
1. **네이버 스마트플레이스**: 가게를 검색하거나 방문하려는 고객에게 업체 정보와 소식을 보여주는 용도. 오프라인 가게의 첫 안내 목적과 잘 맞아 1순위로 판단했다. 사업자·업체 등록과 관리 권한 확보는 별도의 초기 준비다.
2. **카카오톡 채널**: 이미 알고 있는 고객에게 소식을 보여주고 문의를 이어가는 용도. 익숙한 카카오톡 안에서 관리할 수 있으나, 채널 개설과 친구 확보가 필요하다. 기본값은 소식 게시이며 유료 메시지 발송과 구분한다.
3. **인스타그램**: 사진이 구매 판단에 중요한 상품과 짧은 영상 소개에 적합하다. 게시물·릴스 형식과 계정 운영에 익숙해져야 하므로 전체 업종의 첫 추천으로 강제하지 않는다.

세 서비스 모두 처음부터 가입하게 만들지 않는다. **실제 초기 선택은 ‘파일만 저장하기’**다. 순위는 추천 카드의 순서이며 사용자가 계정을 보유했다고 가정한 자동 선택이 아니다.

네이버는 무료 업체 등록과 사진·업체정보 관리를 안내한다. [네이버 등록 안내](https://smartplace.naver.com/help/guide), [스마트플레이스 기능 소개](https://new.smartplace.naver.com/introduction/smartplace).
카카오는 무료 채널 개설과 카카오톡 내 관리를 설명하며, 소식에는 사진·영상 등을 첨부할 수 있다. [채널 만들기](https://kakaobusiness.gitbook.io/main/channel/start), [소식 작성](https://kakaobusiness.gitbook.io/main/channel/run/post).
카카오 메시지는 발송량에 따라 캐시가 차감되는 유료 서비스다. [메시지 안내](https://kakaobusiness.gitbook.io/main/channel/run/message).

## 비용·연동·정책 검토
정액 요금이나 무료 메시지 수는 고정해 적지 않는다. 일반 계정 이용, 소식 게시, 광고 집행, 메시지 발송, API 사용을 서로 구분한다.

| 후보 | 무료·유료 범위 | 기술적 연동 가능성과 제약 | 이번 구현 |
|---|---|---|---|
| 스마트플레이스 | 업체 등록 무료. 광고·유료 부가상품 별도 | 이번 조사에서 범용 소식 작성 공개 API는 확인하지 못함. 검색 API를 게시 API로 간주하지 않음 | 저장·복사·관리 화면 링크 |
| 카카오톡 채널 | 채널 개설 무료, 메시지 발송 유료 | 채널 관계조회·고객파일 API, 카카오톡 공유/메시지 API는 채널 소식 자동 게시와 다름 | 소식 수동 업로드 안내, 유료 메시지는 실행하지 않음 |
| 인스타그램 | 일반 게시와 유료 광고 구분. 상세 광고비·API 관련 사업 조건은 별도 확인 | 공식 Instagram Login API는 Business/Creator 전문 계정과 권한 필요. 이 경로는 Facebook Page 연결 불필요. Facebook Login 경로의 Page 연결 요구와 혼동 금지 | 파일 저장·글 복사만 제공 |
| 네이버 블로그 | 일반 글쓰기와 광고·외부 운영 대행비 구분. 이번 조사에서 세부 부가요금 검증은 하지 않음 | 글쓰기 API는 2020년 5월 종료. 현재 검색 API를 발행용으로 대체할 수 없음 | 수동 글쓰기 안내 |
| 당근 | 기본 비즈프로필 무료, 광고 별도 유료 | 이번 조사에서 일반 비즈프로필 소식용 범용 공개 게시 API는 확인하지 못함 | 수동 소식 작성 안내 |
| 유튜브 쇼츠 | 일반 업로드와 유료 광고 구분. API 할당량은 별도 제약 | videos.insert 사용 가능. OAuth와 업로드 권한·할당량·프로젝트 설정 필요. 최신 문서 기준 재확인 필요 | 저장 영상 직접 업로드 안내 |
| 엑스·쓰레드 | 이번 단계에서 새 API 도입·가격 검토 대상에서 제외 | 기존 프로젝트에 연동 없음. 향후 도입 시 각각 공식 정책 확인 | 기존 출력·문구·검색어·기록 호환 유지 |

연동 판단의 근거:
- [카카오 REST API 공식 목록](https://developers.kakao.com/docs/ko/rest-api/reference): 채널 관련 API와 사용자 메시지 API의 역할 확인.
- [Meta 공식 Instagram Login API 컬렉션](https://www.postman.com/meta/instagram/folder/6raa77c/instagram-api-with-instagram-login): 전문 계정, Facebook Page 불필요, `instagram_business_content_publish` 등 권한 확인.
- [Meta 공식 Facebook Login API 컬렉션](https://www.postman.com/meta/instagram/folder/9cgqucg/instagram-api-with-facebook-login): 다른 인증 경로의 Page 연결 조건 확인.
- [네이버 블로그 글쓰기 API 종료 공지](https://developers.naver.com/notice/article/7527): 종료 시점과 대체 구현 금지 근거.
- [YouTube videos.insert](https://developers.google.com/youtube/v3/docs/videos/insert): OAuth 업로드와 할당량 확인. 예전 할당량 숫자나 비공개 제한을 현재 조건으로 재사용하지 않는다.
- [카카오 채널 운영 가이드](https://business.kakao.com/guide.html?ver=f7cd0aa): 소식·메시지 정책과 업종 제한 확인. 향후 자동 메시지는 플랫폼 정책 검토와 별도 승인 없이 구현하지 않는다.

접근 한계: Meta 개발자 사이트의 content publishing 본문은 이번 도구에서 오류가 발생했다. 위 Meta 소유 Postman 문서를 대체 근거로 사용했다. 카카오 기존 소개 URL은 본문이 거의 없는 셸만 반환하여 공식 GitBook 가이드를 확인했다. 실제 계정 가입·관리자 화면 조작·게시·유료 구매는 수행하지 않았다.

## 업종에 따른 실제 추천 순서
| 선택한 업종 묶음 | 1순위 | 2순위 | 3순위 |
|---|---|---|---|
| 전체 업종 | 스마트플레이스 | 카카오톡 채널 | 인스타그램 |
| 카페·꽃집·소품 등 사진 중심 | 인스타그램 | 스마트플레이스 | 카카오톡 채널 |
| 교육·수리 등 설명 중심 | 스마트플레이스 | 네이버 블로그 | 카카오톡 채널 |
| 동네 생활·방문 서비스 | 스마트플레이스 | 당근 비즈프로필 | 카카오톡 채널 |

업종은 선택 사항이며 서비스가 업종을 자동 추정하지 않는다. 업종을 바꿔도 선택된 채널은 유지한다. 기본 추천에 없는 선택값은 추가 목록을 열어 표시한다. 처음부터 아홉 개 카드를 나열하지 않는다.

## 적용된 사용자 흐름과 보존 방식
홈 ‘홍보물 만들기’ → 사진 선택 → 결과 종류 확인 → 홍보할 곳은 선택 사항 → 설명 수정 → 결과 확인 → 저장/복사 → 해당 서비스에서 직접 올리기.

채널 설정은 `src/channels.ts`, 선택 UI는 `ChannelPicker.tsx`, 결과 안내는 `PublishingGuide.tsx`로 분리했다. 플랫폼 상표 로고를 임의 제작하거나 권리 확인 없이 복제하지 않고 정확한 이름으로 표시한다. 기본 입력은 native radio여서 방향키 선택이 가능하다.

기존 세 ID와 템플릿·색상·검색어 개수를 유지했다. 모든 채널의 추천/수동 검색어를 공통 매핑 함수로 관리하고, 없는 저장값은 현재 정보에서 채운다. 직접 작성한 검색어는 채널·설명 변경으로 덮어쓰지 않는다. 내보내기·읽어주기·초안 복원 코드를 새 API로 교체하지 않았다. 과거 2+1 결과 카드 문제를 새 결함으로 취급하지 않았고 기존 결과 수별 배치를 회귀 검증했다.

## Phase 3 우선순위
1. **실사용 결과 품질**: 미리보기·PNG·영상의 같은 템플릿 렌더링, 제목/가격/기간/위치의 실제 입력, 영상 길이·자막·파일 규격 검증. 채널별 권장 비율을 확인한 후 출력 프리셋 추가. 문구 템플릿에서 확인되지 않은 인기·성과 표현 제거.
2. **저장 안정성**: 현재 메모리 기록을 지속 저장으로 확장하고 파일 용량·만료·삭제·복구 UX 정의. 실제 계정 인증과 체험 흐름 분리.
3. **수동 게시 성공률**: 시니어 소상공인 5명 이상으로 사진 선택→저장→채널 직접 게시 관찰. 막히는 지점과 도움 요청을 기록. 사용자 동의 없이 추적 도구를 추가하지 않음.
4. **검증된 순서로 연동**: 수동 경로가 충분한지 먼저 확인. 필요할 때 Instagram 또는 YouTube의 별도 OAuth 기술 검증, 서버 토큰 보관·취소·중복 게시 방지·사용자 최종 확인 구현. SmartPlace·Blog·Kakao를 존재하지 않는 범용 게시 API로 묶지 않는다.
5. **출시 전 검증**: iOS Safari·Android Chrome 실기기의 사진 권한, 다운로드 위치, 공유, 음성, 키보드 및 200% 확대. 유료 메시지·광고·결제는 이번 단계에 포함하지 않는다.
