## 독립 검토와 Figma 비교

- 상태/생성 연결 검토자가 위의 두 초안 소실 경로를 실제 Chromium에서 재현하고 수정 후 두 경로를 다시 통과했다.
- 블랙박스 검토자가 360×640, 390×844, 430×844, 768×1024, 1440×900에서 실제 동선·캡처 68개, PNG·MP4 다운로드, 복사, 잘못된 사진 교체, 이미지 실패/재시도를 확인했다. pageerror·문서 가로 넘침 없음.
- 접근성 검토자가 같은 다섯 화면 크기×두 글자 모드에서 298개 판정을 확인했다. 주요 보이는 입력·버튼 44px 이상, 메뉴 초점 유지/Escape 복귀, radio와 tab 키보드 조작, 공백 상품명 안내, 긴 한국어, 390×400 높이 축소의 입력·동작 바 겹침을 검사했다. 390×844의 검사한 일반 텍스트 대비 최저 4.85:1.
- [Figma 검토 파일](https://www.figma.com/design/ULjjjsqEBntBLpqVlKksiG)의 Noto Sans KR, 본문18/보조16/버튼20px, 브랜드 색상 변수, 버튼 반경12px와 상태·배치 의도를 읽기 전용으로 비교했다. 이 파일은 검토용 레이아웃이며 앱과 픽셀까지 동일한 명세는 아니다. 앱의 큰 글자 모드와 52px 이상 조작은 실제 렌더링에서 따로 검증했다. Figma 파일을 수정하거나 정상 동작의 증거로 대신 사용하지 않았다.

## 실행 검사

앱 폴더에서 TypeScript·Vite 빌드·문서 링크 검사를 실행한다. 신규 검증 파일은 oxfmt 형식 검사와 Node 구문 검사를 통과했다. 별도 lint 명령/설정은 없다. 오래된 교수/phase 검사에는 역사적 UI 선택자가 남아 있으므로 이번 앱 동선은 아래 현재 검사로 확인한다.

| 검사 | 범위 |
|---|---|
| `pnpm verify:mobile-flow` | 다섯 요구 뷰포트×두 모드, 선택 전 재진입·빈 내 홍보물 초안 보존, 3출력 순서, 상품명 단독/공백, 실제 PNG·영상 다운로드, 오류 복구·명시적 새 작업 |
| `pnpm verify:submission` | 12 프로필, 360×640·390×844 빈/선택 업로드 한 화면 배치, 320×568·가로형·긴 입력, 선택별 결과·공통 미디어 규격 |
| `pnpm verify:results` | 7개 폭×두 모드, 저장/복사 조작 일관성·대비·확대·재생·키보드 탭·파일 저장·복사 실패·영상 준비 취소 |
| `pnpm verify:usability` | 20 프로필, 메뉴·사진 선택/교체·초점·초안·결과·내 홍보물·개별 제작·명시적 새 작업 |

선택별 실제 생성 연결도 테스트 페이지에서만 호출 계수로 확인한다. 포스터는 Canvas PNG 준비 1회·영상 시작 0회이며 저장 때 캐시 파일을 쓴다. 영상은 PNG 준비 0회이고 영상 저장 요청 때만 MediaRecorder가 시작된다. 결과를 숨기는 것만으로 통과 처리하지 않는다. 실패/지원 제한/TTS 대역과 계수는 테스트 페이지에만 주입하며 앱의 정상 경로에는 모의 응답을 추가하지 않았다. 유료 API 호출 없음.

## 통합·검증 범위와 한계

- actual application은 Canvas 포스터·MediaRecorder 영상·규칙 기반 문구를 만드는 브라우저 체험형이다. 실제 AI·인증·클라우드 보관·공유 API는 미연결이다. 저장은 실제 파일 다운로드, 문구는 실제 clipboard 동작으로 확인했다.
- 초안과 내 홍보물은 열린 창의 메모리 기록이며 새로고침 후 영구 복원되는 저장소가 아니다. 화면의 저장/복사 안내를 유지한다.
- safe-area와 reduced-motion은 CSS와 Chromium으로 검사했다. 실물 휴대전화·실제 가상 키보드·Safari/VoiceOver·실사용자 인터뷰는 별도다.
- main의 다른 팀 C/E 모듈·환경 예제·기존 문서 삭제 등은 통합 시 보존한다. 호스팅 설정·유료 API·의존성을 추가/변경하지 않는다.
- 이 문서는 코드 게시 전 검증 스냅샷이다. 최종 커밋·PR·병합 여부와 자동 배포 상태는 GitHub PR 및 사용자 최종 보고에서 확인한다. 병합된 main의 깨끗한 worktree에서도 실제 체크를 실행한다.
- 캡처·세부 측정은 작업 공간 `output/final-integration-review/agent-blackbox/`, `agent-accessibility/`, `pre-merge/`에 있다. 생산 경로에는 테스트 산출물과 캡처를 넣지 않는다.
