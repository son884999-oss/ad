# 홍보잇다 앱 (ad_prototype)

상품 사진 한 장으로 포스터 · 10초 영상 · 홍보 글을 만드는 모바일 웹앱입니다. React 19 + Vite + TypeScript, Vercel 함수(`api/`).

```powershell
npx -y pnpm@9.15.9 install
npm run dev        # http://localhost:5173 (실제 AI, .env.local 필요)
npm run dev:mock   # http://127.0.0.1:5174 (가짜 AI 답, 비용 없음)
npm run build
```

설치·키 설정·점검 명령·배포·지금 상태는 **[docs/README.md](docs/README.md)** 한 곳에 있습니다.
