# Visit Holy Korea 차용 후보 검토 — 교수 상의용, 미적용

기록: 2026-10-13 KST. 참고: [Visit Holy Korea](https://visitholykorea.com/).

**사용자 요청 범위:** 차용할 부분을 검토해 기록만 남긴다. 교수님과 상의한 뒤 판단할 자료이며, 이 검토를 근거로 추가 UI 수정은 적용하지 않는다.

## 관찰 방법과 증거

- 실제 브라우저에서 1440×900 데스크톱, 390×844 모바일, 320×568 좁은 화면을 관찰했다.
- 홈 첫 화면, 카드 구역 스크롤, 사진의 다음 버튼, 글자 크기 메뉴 펼침을 확인했다.
- 글자 크기 옵션은 ‘대/기본’으로 표시된다. 옵션을 선택하여 지속 설정을 바꾸지는 않았다.
- 모바일 본문에는 세 개의 행동 카드가 세로로 배치되고, 하단에는 홈·성지 찾기·기록·성지 일정·더보기가 표시된다.
- 390px에서 행동 카드는 약 348×71px. 두 카드는 흰색, ‘오늘의 성지 일정’은 짙은 남색 채움과 흰색 글씨로 구별됐다. 아이콘·굵은 제목·짧은 설명·오른쪽 화살표가 함께 있다.
- 사진 슬라이드에는 이전/다음과 위치 표시 점이 있다. 여러 관찰 사이 사진과 제목이 바뀌었다. 자동 이동과 수동 다음 클릭의 개별 효과를 정밀 분리한 것은 아니다. 전체 자동 재생 제어·reduced-motion 동작은 미검증이다.
- 사이트의 정보 정확성, 실제 로그인·AI 안내·여행 일정 기능은 검증하지 않았다. 이번 자료는 UI 참고 조사다.

## 그대로 차용하지 않을 부분 / 판단 보류

1. **관광 사이트의 큰 사진을 그대로 메인 구조로 복사:** 홍보잇다는 제작 도구이므로 시작 행동이 먼저 이해돼야 한다. 샘플 전시는 CTA를 보조하는 역할로 제한한다.
2. **끊임없는 자동 슬라이드:** 사용자가 정해 둔 배경 카드 순환의 참고는 되지만 자동 움직임의 속도·멈춤·읽기 방해·움직임 줄이기를 따로 검토한다. 현재 사이트가 접근성 기준을 모두 충족한다고 가정하지 않는다.
3. **가운데 크게 올라온 기록 버튼:** 참고 사이트의 목적과 홍보잇다의 주 행동은 다르다. 내 홍보물이 만들기보다 시선을 강하게 끌게 할지는 교수님과 상의한다.
4. **작은 화면의 보조 기능 밀도:** 헤더에는 로고·글자·AI 안내·언어가 모여 있다. 홍보잇다에 같은 개수를 도입하면 혼잡해질 수 있다. 필요한 기능만 남긴다.
5. **설명/행동 카드의 수 증가:** 카드 디자인이 좋다고 CTA를 늘리지 않는다. 사용자의 후속 홈 방향인 만들기 버튼+3단계를 우선한다.
6. **브랜드 색·서체·로고의 교체:** 현재 홍보잇다 공식 정체성을 유지하며, 차용 범위는 위계·배치·정렬 원칙이다.

## 전문가 관점의 대안 비교

- A 시니어 UX / B 정보구조: 전면 만들기와 짧은 단계 안내를 먼저 파악하도록 요구. 관광 탐색형 구성 전체를 따르지 않는다.
- C 시각 디자인 / D 에셋: 실제 결과물 중심 전시는 효과적이지만 텍스트와 결과 카드가 시각적으로 경쟁하지 않게 한다.
- E 접근성: 큰 클릭 영역·명확한 선택 상태는 후보. 아이콘만 있는 글자 크기, 자동 순환 제어, 실기기 안전 영역은 그대로 통과 판정할 수 없다.
- F 프런트엔드 / G QA: 현재 소스에 구현하지 않고, 교수 판단 뒤 하나의 구체적인 안으로 시안·검증 범위를 정한다.

대안 A는 ‘큰 결과물 배경+고정된 전면 CTA/단계’, 대안 B는 ‘정적인 전면+아래 샘플 카드 구역’이다. A는 품질 전시에 강하지만 대비·움직임 검증이 더 필요하다. B는 읽기가 안정적이나 첫 화면의 전시력이 약할 수 있다. 사용자가 제시한 후속 방향은 A에 가깝다. 이번에는 우열을 확정하거나 구현하지 않는다.

- 샘플은 배경 카드 / 아래 카드 구역 / 큰 단일 결과 중 어떤 표현이 사용자 이해에 맞는가?
- 보조 가이드를 설정으로 옮겼을 때 어떤 안내를 첫 화면에 남겨야 하는가?
- 글씨 크기 진입을 헤더에서 직접 드러낼지, 현재 설정 경로를 유지할지?
- 순환 속도·멈춤·정지된 큰 글씨 모드를 어떻게 보여줄지?
