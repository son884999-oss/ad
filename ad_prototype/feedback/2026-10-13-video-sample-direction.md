# 영상 샘플 제작 도구 방향 — Google Flow 검토

기록: 2026-10-13 KST. 사용자가 Higgsfield 대신 Google Flow로 영상을 만드는 방향이 가능한지 질문했다.

- 현재 UI/UX·디자인 시안의 **샘플 제작 도구 후보로 Google Flow를 검토**한다. 비용 집행·구독·영상 생성·제공사 변경을 완료했다는 뜻이 아니다.
- 실제 홍보잇다 자동 생성 기능 연결은 향후 작업이다. Flow로 사람이 만드는 샘플과 Google 개발자 영상 API로 자동 생성하는 기능을 분리해서 계획한다.
- Google 공식 개발자 문서는 Veo의 사진 기반 영상 및 9:16 출력을 안내한다. 실제 연동 시점에 모델·지역·요금·제한·API 방식을 다시 확인한다.
- Google Flow 공식 안내에는 한국에서 표시 워터마크가 자동 적용된다고 명시돼 있다. 시안에 넣기 전에 실제 다운로드 파일의 표시와 품질을 확인한다.
- Higgsfield와의 우열은 이번에 실물 결과를 비교하지 않아 확정하지 않는다. 같은 제품 사진으로 형태 보존·움직임·화면 구성·원하는 홍보물 분위기를 비교하는 샘플 평가를 권장한다.
- Flow에서 보이는 샘플과 향후 선택할 API 모델의 결과가 같다고 약속하지 않는다. 결과물의 실제 제공 가능 범위를 확인한 뒤 홈의 품질 전시 카드에 사용한다.

확인한 공식 출처:

- [Google Flow 시작 안내](https://support.google.com/flow/answer/16353333?hl=en)
- [Veo 영상 생성 개발자 문서](https://ai.google.dev/gemini-api/docs/veo?hl=en)

이 메모는 제작 방향 검토 기록이다. 현재 앱에 새 영상 API·백엔드·결제 기능을 연결하지 않았다.
