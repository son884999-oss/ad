# 홍보잇다 Phase 4-B 에셋 계획

지침 원본은 `HASE4B_MASTER.md`다. 요청한 `PHASE4B_MASTER.md`와 파일명만 다르며 내용을 모두 확인했다. 승인한 C안과 사진→설명→결과의 기존 동작을 유지한다.

2026-10-10 수정 지침과 사용자 요청 반영: 시니어 사용성을 최우선으로, 읽어주기를 첫 줄에 노출하고 시작 버튼 → 3단계 안내 → 예시 이미지 순으로 배치한다. 에셋을 동시에 노출하는 것보다 글자·다음 행동을 찾기 쉬운 위계를 우선한다. 입력 화면의 중복 삽화는 생략하고 `workflow-details`는 홈 안내에 사용한다.

## 제작·통합 기준

Corporate Flat 스타일, 얇고 일정한 남색 선, 주황·피치·아이보리·옅은 하늘색. 생성 이미지에 읽어야 할 글자를 넣지 않고 실제 한국어 안내는 React로 표시한다. 인물이 필요한 히어로에만 25–45세 성인 1명을 작게 사용하며 제품 화면이 중심이다. 다른 이미지에는 불필요한 인물을 넣지 않는다.

대표 이미지는 단색 아이보리 배경, 작은 삽화는 실제 alpha를 가진 투명 배경을 요청한다. 원본 PNG와 프롬프트는 `design-assets/illustrations/phase4b/`, 배포용 WebP는 `public/assets/illustrations/phase4b/`에 보관한다. 기존 에셋은 삭제하지 않는다. 파일별 크기·용량·alpha·적용 위치를 manifest에 기록한다.

진행 체크: 원본 저장 → 실제 이미지 검토 → 최적화 → 컴포넌트 연결 → 모바일·PC 캡처 → 자체 3관점 검토 → 기능 회귀 검증. 완료 보고는 실제 적용과 테스트 증거가 있을 때 작성한다.
