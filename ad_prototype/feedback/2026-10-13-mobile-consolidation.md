## 판단 근거와 기록의 우선순위

10/08 멘토링은 모바일 화면설계·주요 화면 연결·단계 안내·간편모드·읽어주기를 요구한다. 10/12 교수의 명시적 재요청은 지속되는 하단 바로가기와 모바일 화면 구성이다. 제공된 10.12.b 이미지는 시각 참고이며, 이 이미지에 등장하는 모든 기능이 확정 요구인 것은 아니다.

원문 피드백, 모바일 참고 구현 기록, UI/UX 구현 기록, 통합 체크리스트, 유지보수 정책과 디자인 원칙을 대조했다. 예전 기록의 ‘만들기 선택창과 메뉴 분리’, ‘PC 내비게이션 유지’는 당시 기준이다. 최신 사용자가 통합 메뉴와 PC 별도 화면 폐기를 명시했으므로 이번 구현 기준을 변경했다. 이전 문서의 검증 수나 완료 판정을 이번 코드의 검증 증거로 재사용하지 않는다.

## ‘사진 입력하고 다음’의 역할

이 문구는 사진 단계에서 설명 단계로 이동하는 버튼이었다. 설명 입력에서 결과 보기와 같은 역할이 아니다. 삭제하면 사진→설명 진행 수단이 없어지므로 사진 단계에 `설명 적기`로 남겼다. 설명 단계의 주 버튼은 `결과 보기`다. 기존 뒤로 가기·사진 변경·입력 유지·복원 동작은 유지한다.

세 화면의 공통 의도는 결과를 시각적으로 구분하고 다음 행동(선택·재생·복사)을 가깝게 두려는 것으로 해석할 수 있다. 그러나 이는 이미지에 근거한 해석이며 교수님의 실제 설명을 대신하지 않는다. 결과 화면의 이미지·영상·문구 3탭은 산출물 종류 구분이고, 6번 목적 카테고리나 8번 글 용도와는 다른 분류 축이다. 두 축을 모두 한 줄에 섞으면 다시 복잡해질 수 있으므로 후속 설계를 결정한 뒤 도입한다.

이번에는 기존 개별 제작 경로를 통합 메뉴에 남겼으며 템플릿 갤러리·복수 영상 생성·SNS/블로그/상세 설명 3종 생성은 새로 구현하지 않았다. 레퍼런스의 15초 표기는 예시다. 영상 공급자/API 선택이나 길이를 이 이미지로 확정하지 않는다.

## 후속 홈 방향: 이번 시안과 구분

사용자가 제시한 ‘샘플 완성 후 홍보물 만들기 버튼과 3단계 안내만 중심에 남기고, 고품질 포스터·영상·문구 카드가 배경에서 움직이는 홈’은 기존 후속 홈 방향 문서에 보존돼 있다. 현재 홈은 교수 레퍼런스에 맞춘 정적인 체험 예시를 사용한다. 카드 움직임·실제 샘플 품질·움직임 멈춤·줄인 동작 설정은 다음 논의 대상이다.

Holy Korea의 버튼·카드·정보량·모바일 배치 차용 검토는 별도 기록에 보존했다. 이번 구현의 새 요구로 가져오지 않았다. Flow/Veo는 향후 영상 샘플 후보이며 현재 API 연동과 별개다.

## 실제 검증 자료

최종 수치와 화면은 `화면/qa-matrix-final.json` 및 동일 이름의 JPG에 연결된다. 큰 화면에서는 프레임 너비 560px, 작은 화면에서는 실제 가용 너비를 사용한다. 간편모드 입력 글씨 22px, 결과 주 버튼과 하단 메뉴 경계, 결과 진입 탭 위치, 의도하지 않은 가로 넘침을 확인한다. `focus-390x450.json`은 낮은 화면에서 이름·소개·특징 초점 위치를 기록한다. 복사·다운로드·확대·메뉴 진입의 상세 결과는 별도 최종 검증 기록에 남긴다.

이미지 예시는 실제 AI 생성이 아닌 기존 사진 기반 로컬 PNG다. 영상도 기존 로컬 예시다. 실제 휴대폰 하드웨어·OS 가상 키보드·음성 품질·실서비스 저장·인증·결제·API 성공률은 이번 브라우저 크기 검증만으로 확인한 것으로 표시하지 않는다.
