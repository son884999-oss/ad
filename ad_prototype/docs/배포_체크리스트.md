# 홍보잇다 배포 체크리스트 (2026-10-18)

실제 배포(Vercel)까지 남은 일입니다. **[완료]**는 코드로 끝낸 것, **[사용자]**는 계정·결제·설정 권한이 있어야 해서 직접 하셔야 하는 것입니다.

## 1. 코드 준비 — 끝남

- [완료] 유료 호출 보호
  - `VIDEO_ENABLED=1`이 없으면 유료 호출을 하지 않습니다.
  - 주소마다 분당 3번까지만 받습니다.
  - 그날 하루 장면·영상을 각각 최대 `DAILY_PAID_LIMIT`번(기본 5)까지만 만듭니다.
  - `PREMIUM_ACCESS_CODE`를 넣으면 코드를 가진 기기만 유료 고급형을 쓸 수 있습니다. (`api/_lib/paid.js`)
- [완료] 시연 기기 설정: 시연 휴대폰에서 `https://주소/?demo=코드`로 한 번 열면 됩니다.
  - 그 기기는 코드를 기억하고, 고급형이 기본으로 선택됩니다.
  - 주소창에서는 코드가 지워져서 화면을 공유하거나 캡처해도 코드가 남지 않습니다.
- [완료] 배포 결과물 점검
  - 키·비밀값이 들어 있지 않습니다.
  - 개발용 "내 컴퓨터에 저장" 호출이 빠져 있습니다.
- [완료] Gemini 두 번째 키 지원(`GEMINI_API_KEY_2`): 첫 키가 한도에 걸린 뒤에만 쓰고, 하루 100원까지만 씁니다.
- [완료] 점검 묶음 모두 통과: `npm run verify:*`, `audit:screens`, `eval:poster`, `eval:promo`.

## 2. 사용자가 할 일 — 권한 필요

### Gemini 키 (가장 먼저)
- 지금 `GEMINI_API_KEY`는 **무료 등급**입니다. `gemini-2.5-flash-lite` 기준 하루 20번까지라 시연·배포에 부족합니다.
  - 홍보물 하나에 2~3번(사진 분석, 홍보 글, 필요하면 다시 쓰기)이 들어가서 하루 7개 정도면 끝납니다.
- `GEMINI_API_KEY_2`가 속한 프로젝트는 요청 한도가 **0**으로 응답합니다(`quota_limit_value: 0`).
  - 한도를 다 쓴 게 아니라 처음부터 허용량이 0이라는 뜻입니다.
  - 결제된 프로젝트(risu, Tier 1)의 키라면 AI Studio → 그 프로젝트 → 사용량·한도 화면에서 한도가 0인지, 지출 상한(spend cap)이 걸렸는지 확인해 주세요.
- 권장: **결제된 프로젝트의 키를 `GEMINI_API_KEY`(첫 키)로** 넣으세요.
- 하루 상한을 확실히 막으려면 Google Cloud 콘솔 → 할당량에서 Generative Language API의 "하루 요청 수"를 직접 낮춰 두세요. 결제 예산 알림은 알림만 보내고 호출을 막지는 않습니다.

### Vercel 설정
1. 프로젝트 루트 디렉터리: `ad_prototype`
2. 환경 변수 (Production과 Preview 모두):
   | 이름 | 값 |
   |---|---|
   | `GEMINI_API_KEY` | 결제된 프로젝트의 키 |
   | `GEMINI_MODEL` | `gemini-2.5-flash-lite` (지금과 같음) |
   | `HF_CREDENTIALS` | Higgsfield `KEY_ID:KEY_SECRET` |
   | `VIDEO_ENABLED` | `1` |
   | `PREMIUM_ACCESS_CODE` | 시연용 코드 (짧고 추측하기 어렵게) |
   | `DAILY_PAID_LIMIT` | `5` |
   | `ALLOWED_ORIGINS` | 직접 연결한 도메인이 있을 때만 (예: `https://hongboitda.kr`) |
3. 방화벽(권장): Vercel Firewall에서 `/api/*` 요청 수 제한 규칙을 추가합니다. 코드 안의 제한은 서버 인스턴스마다 따로 세서 완벽하지 않습니다.
4. 배포 순서: `feature/UI-Screen` 미리보기(Preview) 배포 → 시연 휴대폰으로 점검 → 팀 합의 후 `main`에 합치기(PR) → 운영 배포.

### 비용 상한
- Higgsfield: 미리 충전한 금액이 진짜 상한입니다(추가 충전 20달러).
  - 5초 영상 1개는 약 0.21~0.31달러, 장면 1장은 그보다 쌉니다.
  - 고급형 1번에 장면 1장 + 영상 1개가 들어갑니다.
- 하루 5번 제한(`DAILY_PAID_LIMIT`)은 서버 인스턴스마다 따로 세는 느슨한 상한입니다. 여러 인스턴스가 떠도 정확히 세려면 공유 저장소(Upstash Redis, Vercel Marketplace)가 필요합니다. 회원가입·서버 기록 작업 때 같이 하는 것을 권합니다.

## 3. 시연 당일 점검

1. 시연 휴대폰으로 `?demo=코드` 주소를 한 번 엽니다. 고급형이 기본 선택인지 확인합니다.
2. 미리 한 번 만들어 봅니다. 걸리는 시간은 배경 약 1분, 영상 1~3분, 자막·편집 약 10초입니다. 진행 단계가 3칸으로 보입니다.
3. 와이파이를 확인합니다. 영상 파일이 5~6MB입니다.
4. 실패하면 자동으로 원래 사진과 예시 영상으로 결과가 나옵니다. 화면이 멈추지 않습니다.
5. 그날 만들 수 있는 수(5번)를 다 쓰면 "오늘 만들 수 있는 AI 영상을 다 만들었어요"가 나옵니다.

## 4. 배포 뒤 할 일 (이미 정한 방향)

- 내 홍보물 기록 → 서버 + 회원가입·로그인 (기기 저장이 무거워지는 문제 해결)
- 10초 영상: `HF_VIDEO_DURATION=10`, 비용 2배
- 고급형 연출: 원본 사진 한 장에서 시작해 제품별 세계(초콜릿 강, 숲, 계곡 등 프리셋 중 무작위)로 바뀌는 영상 1개. 코드 완료, **실제 영상 확인은 다음 유료 허용 때 1번** (api/_lib/video-prompt.js )
