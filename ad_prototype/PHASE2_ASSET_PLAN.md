공통: Corporate Flat Vector Illustration 느낌의 실제 생성 이미지. 성숙한 한국인 성인, 자연스러운 인체 비례, 얇은 남색 윤곽선, 민트·피치·하늘색·아이보리, 깨끗한 2D 면, 최소 그림자·질감. 투명 배경으로 생성하며 alpha를 보존한다. 이미지 안에는 브랜드·플랫폼 로고·문장을 넣지 않고 의미 있는 한국어는 HTML로 표시한다.

첫 대표 이미지를 이후 이미지의 스타일 참조로 사용한다. 개별 원본을 확인한 뒤 선택하고, 원본은 프로젝트 안의 원본 보관 폴더에, 배포 이미지는 public/assets/illustrations/에 둔다. 실제 생성 프롬프트·파일 정보·도구 모드는 제작 후 별도 manifest에 기록한다.

생성 모드는 기본 내장 image_gen 도구다. CLI/API 유료 호출은 사용하지 않는다. hero는 서비스 설명용 대체 텍스트를 제공하고, 단계별 이미지처럼 주변 문장과 의미가 중복되는 경우 빈 대체 텍스트로 중복 낭독을 피한다. 고정 비율·크기와 lazy loading을 사용한다.
