# 홍보잇다 — 선택한 C안 적용 결과

후속 작업: 20개 에셋의 제작·실제 통합과 전체 검증은 [Phase 4-B 최종 보고서](PHASE4B_FINAL_REPORT.md)에 기록했다. 아래는 C안 선택 직후의 제한된 로고 적용 기록이다.

2026-10-09. 사용자 요청 **‘사진의 세번째 안으로 진행’**에 따라 C안 ‘오가는 흐름’을 선택 로고로 적용했다. 이전 자체 평가의 A·D 추천보다 사용자의 C안 선택을 우선했다.

## 실제 적용

생성 시안의 넓은 왼쪽 고리, 상승하는 오른쪽 끝, 주황·남색 교차를 순수 SVG 면으로 정리했다. 가로 조합에서는 작은 헤더에서도 심볼이 보이도록 비중을 조정하고 한글과 수직 중심을 맞췄다. 심볼·한글·가로 조합 모두 이미지가 내장된 SVG가 아닌 실제 path다. 기본 가로 조합은 **2,918 bytes**다.

`BrandLogo`를 통해 홈과 작업 화면의 헤더, 전체 메뉴, 로그인에 동일 로고를 연결했다. 기존 ∞ 문자 표시는 교체했다. 이름은 **홍보잇다**, 홈 버튼의 접근성 이름은 **홍보잇다 홈**을 유지했다. 브라우저 favicon과 180px 터치 아이콘도 같은 C안을 사용한다. 제목·description·Open Graph의 정확한 서비스명은 보존하고 브라우저 theme-color를 아이보리로 변경했다.

주요 행동은 진한 주황, 선택 영역은 옅은 피치, 본문은 남색, 바탕은 아이보리로 정리했다. 밝은 심볼 주황을 버튼 글자에 그대로 사용하지 않았다. 피치 카드의 설명 대비를 위해 보조 글자는 `#625E59`로 조정했다. 민트 계열의 기존 삽화와 출력 콘텐츠, 채널 고유 색상은 보존했다.

대표 삽화를 다시 생성하거나 모든 Phase 4 시각 작업을 완료했다고 주장하지 않는다. 이번 작업은 사용자가 선택한 로고의 정리와 서비스 적용이다. 기존 생성 심볼을 바탕으로 코드 기반 벡터를 제작했으며 이번 턴에 imagegen을 다시 호출하지 않았다.

## 화면 검토와 개선

- **시니어 UX**: 한글 이름을 심볼과 항상 함께 표시한다. 320px에서 헤더가 두 줄로 밀리는 현상을 확인하고 로고 너비를 160px로 조정했다. 그 밖에는 182px이며 홈 버튼의 간편모드 터치 높이는 60px다.
- **프론트엔드**: 순수 SVG로 축소·확대와 폰트 로딩의 영향을 줄였다. 공통 컴포넌트를 사용해 화면별 로고 불일치를 예방했다. 앱 runtime 의존성을 추가하지 않았다.
- **디자인**: C안의 비대칭 형태를 유지하고 심볼과 글자의 수직 정렬을 보정했다. 컬러·어두운 배경·단색·16/24/32/96px을 캡처해 검토했다. 16px에서는 교차면보다 고리의 실루엣이 주요 식별 요소다.

위 내용은 세 관점의 자체 검토이며 실사용자 조사나 독립 전문가 심사 결과는 아니다.

## 검증

| 실행 | 결과 |
|---|---|
| `node scripts/verify-selected-brand.mjs` | 320/375/390/430/768/1024/1440px의 홈·메뉴·로그인 로고, 가로 넘침·메뉴 간섭 없음, 비율·한글·순수 SVG·수직 정렬 확인 |
| `node scripts/verify-phase3.mjs` | 7개 너비 × 5개 화면, 사진→설명→결과, 단계 복귀·입력 보존·설정·알림·동작 줄이기 통과 |
| `node scripts/verify-ui.mjs` | 10개 결과 배치, 3가지 결과 조합, 입력 검증, 복사, PNG·영상 다운로드 통과 |
| `node scripts/verify-phase2.mjs` | 12개 화면 설정, 9개 채널, 업종 추천, 키보드 선택, 수동 검색어·작업 복원·기존 삽화·주요 대비 통과 |
| TypeScript `--noEmit` | 통과 |
| `npm run build` | 최종 수정 후 통과 |

실제 계산한 대비: 본문/아이보리 **11.66:1**, 보조 글자/아이보리 **6.10:1**, 보조 글자/피치 **5.22:1**, 흰색/주요 버튼 **5.57:1**, 강조 글자/선택 면 **4.85:1**, 입력 경계/흰색 **4.42:1**. 전체 접근성 인증이나 실물 휴대전화 검증을 의미하지 않는다.

최종 소스에서 로고 검증과 production build를 다시 실행했다. 전체 기능 회귀 검증 이후 변경은 로고의 수직 정렬과 보조 글자의 대비 보정뿐이다. 선택 로고 기록·캡처는 `ui-review/phase4b/`, 전체 흐름 회귀 기록은 기존 `ui-review/phase3/` 등 각 검증 출력 위치에 있다.
