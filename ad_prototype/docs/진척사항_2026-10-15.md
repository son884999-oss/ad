## 오늘 한 일

### 1. UI/UX (모바일·PC)
- PC 규칙을 `src/pc-layout.css`로 분리했습니다. 모든 규칙이 `html[data-layout=pc]`로 시작합니다.
- **PC:**
  - 1120px 그리드에 머리말·제목·본문 시작선을 통일했습니다.
  - 따뜻한 배경 위에 흰 카드를 놓아 배경과 카드가 구분되게 했습니다.
  - 보조 버튼 테두리 대비를 3:1 이상으로 올렸습니다.
  - 결과 화면 오른쪽을 하나의 패널로 묶었습니다.
  - 홈 위아래의 빈 공간을 없앴습니다.
  - `DesktopStage.tsx`의 기본 보기는 아직 `"mobile"`(휴대폰 프레임)입니다. PC 화면이 완성됐으니 `"auto"`로 바꿀지는 아래 할 일에 있습니다.
- **모바일:**
  - 1024×844 휴대폰 프레임에서 예시 사진이 하단 메뉴에 가리던 문제를 고쳤습니다.
  - 14px 미만이던 글자를 모두 14px 이상으로 올렸습니다.
  - 카드·버튼의 모서리와 테두리를 통일했습니다.

### 2. 쉬운 모드 (제품 핵심, ATM "쉬운 거래" 방식)
- **이름:** 기본/크게 → **기본/쉬운**. 화면 낭독기 이름도 보이는 글자와 맞췄습니다(접근성 2.5.3).
- **쉬운 한국어:** 문구 약 230개를 `src/easyText.ts`로 옮겼습니다. 예: 다운로드 → 폰에 저장, 해시태그 → # 꼬리말, 필수/선택 → 꼭 써요/안 써도 돼요.
- **음성 입력** (`src/useVoiceInput.ts`, `src/VoiceField.tsx`):
  - 쉬운 모드에서 입력칸을 누르면 마이크가 켜집니다. Tab으로 들어갈 때는 켜지지 않고, "말로 하기" 버튼으로 켤 수 있습니다.
  - 말한 내용이 기존 글(자동으로 채운 글 포함)을 **대체**하고, 10초 동안 **되돌리기**를 보여줍니다.
  - 지원하지 않는 브라우저(Firefox, Safari 일부)에서는 안내 문구를 보여주고 글자로 입력하게 합니다.
- **아이콘과 이모티콘:** 쉬운 모드에서는 뜻이 있는 아이콘(마이크, 재생)만 남기고 빼서, 그 자리를 큰 글씨로 채웠습니다.
- **메뉴:** "만든 것 보기" 아래 항목들도 만들기 카드와 같은 크기의 큰 카드로 만들었습니다.
- **내 홍보물:** **목록 ↔ 격자** 전환을 추가했습니다. 쉬운 모드는 격자가 기본이고, 고른 방식을 기억합니다.
- **결과 탭:** 하나의 분리형 컨트롤로 다시 디자인했습니다. 선택된 탭은 색만이 아니라 밑줄·굵기·테두리로도 구분됩니다.
- **3단계 안내와 홈 여백:** 쉬운 모드의 3단계 안내를 크게 했고, 홈의 3단계 카드에 여백을 확보했습니다.

### 3. AI 통합 (팀 모듈 B·C·D·E 합침)
- **서버 API:** `api/` 폴더에 Vercel 함수로 만들었습니다. 개발 서버에서도 같은 코드가 돕니다.
- **사진 분석** (`/api/analyze-photo`, Gemini `2.5-flash-lite`):
  - 사진을 고르는 순간 한 번만 호출합니다.
  - 제품명, 설명, 고객층, 분위기(복수)를 **비어 있는 칸만** 채웁니다.
  - 실사인지와 흐린지도 함께 판정합니다.
- **분위기 복수 선택:** 고른 순서대로 저장하고, 첫 번째 분위기가 포스터 테마와 홍보 글의 마무리 문장을 정합니다.
- **홍보 글** (`/api/promo-text`): B의 규칙을 Gemini로 옮겼습니다. 12초 안에 답이 없으면 템플릿 결과를 씁니다.
- **포스터:** D의 렌더러를 채택했습니다. 포스터 제목이 두 번 찍히던 버그도 해결됐습니다.
- **실제 키 확인:** 사진 분석은 3~4초, 홍보 글은 약 5초에 200 응답을 받았습니다. 무료 키는 가끔 느리거나 분당 한도(429)에 걸리는데, 그때도 템플릿 결과로 정상 진행됩니다.

### 4. 사진 검사와 카메라/앨범
- **즉시 검사(무료, 브라우저):** 흐림, 너무 어두움, 너무 밝음, 너무 작음을 확인합니다. 기준값은 `src/photoQuality.ts` 맨 위 주석에 있습니다.
- **AI 검사:** 실사가 아닌 사진(그림, 캡처 등)을 걸러냅니다.
- **문제가 있을 때:** **다시 찍기**와 **이 사진 그대로 쓰기**를 보여줍니다. 막다른 길은 없습니다.
- **미리 안내:** 업로드 칸 제목을 "가게나 제품을 직접 찍은 실사 사진을 넣어 주세요"로 바꿨습니다(쉬운 모드: "직접 찍은 사진을 넣어 주세요").
- **카메라/앨범:** 휴대폰에서는 "카메라로 찍기"와 "앨범에서 고르기" 두 버튼을, PC에서는 파일 선택과 끌어다 놓기를 제공합니다.
- **예시 사진:** 공간이 부족하면 **▸ 사진 예시 보기**로 접힙니다.

### 5. 영상 (A·E 통합)
- **흐름:** `/api/video-start` → `/api/video-status`(5초마다 확인) → 완성되면 실제 영상으로 교체됩니다. 대기 중에 취소하면 환불됩니다(`/api/video-cancel`).
- **MVP 설정:** **Kling 2.5 Turbo Standard, 720p, 5초, 소리 없음, 약 $0.21(약 290원)/편.** 소리와 배경음은 나중에 FFmpeg로 넣습니다.
- **대안 모델:** Wan 3.0도 `HF_VIDEO_MODEL`로 고를 수 있습니다(코드와 테스트 있음, 실제 생성 안 해 봄).
- **키가 없으면** 지금처럼 브라우저에서 만든 예시 영상을 씁니다.

## 다른 PC에서 이어서 하기

1. 코드를 받습니다.
   ```powershell
   git fetch origin
   git checkout feature/UI-Screen
   git pull
   cd ad_prototype
   pnpm install
   ```
2. **`.env.local`은 Git에 없습니다.** 새 PC에서 `ad_prototype/.env.example`을 `.env.local`로 복사하고 키를 다시 넣어야 합니다.
   ```
   GEMINI_API_KEY=...            # Google AI Studio에서 발급(무료)
   GEMINI_MODEL=gemini-2.5-flash-lite
   HF_CREDENTIALS=KEY_ID:KEY_SECRET
   ```
3. `pnpm dev`로 실행한 뒤 http://localhost:5173 을 엽니다.

## 주의 사항

- **키 보안:** 키는 `.env.local`에만 넣습니다. 채팅, 코드, `.env.example`에는 넣지 않습니다.
- **비용:** Higgsfield 키를 넣고 개발 서버를 재시작하면, 브라우저에서 홍보물 만들기를 누를 때마다 영상 1편이 실제로 청구됩니다. 자동 검증 스크립트는 청구되지 않습니다.
- **무료 Gemini 키:** 무료 등급은 입력 데이터가 Google 학습에 쓰일 수 있습니다. 시연에는 예시 사진을 쓰세요.
