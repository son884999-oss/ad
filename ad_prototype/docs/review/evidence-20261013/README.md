# 검증 자료의 현재 범위

최신 사용자 요청으로 사진 단계의 채널·결과 종류 선택과 고정 안내 바를 제거했다. 버튼은 본문의 ‘다음 단계’다. 설명 화면의 추가 설정은 비활성화해 렌더링하지 않는다.

- 현재 사진/설명/직접 결과 진입: `simplified-flow-checks.json`, `simplified-flow-sizes.json`.
- `photo-next.png`, `details.png`, `results.png`는 위 간소화 이후 캡처다.
- `photo-next-checks.json`은 고정 안내 바가 있던 이전 검증 자료다. 해당 바는 현재 제거됐으며 이 수치를 최신 배치로 재사용하지 않는다.
- `checks.json`은 앞서 검증한 로그인 시안·글씨 크기·예시 저장/복사·기록 경로의 기록이다. 모든 항목을 모든 크기에서 반복한 것은 아니다.
- `home-sizes.json`과 `home.png`는 유지된 현재 커피 홈 구성의 자료다.

실제 AI·인증 서버·결제·실기기 키보드·음성 품질은 미검증이며 UI 시연과 구분한다.
